# P03: 소개 역할 그리드

## 목표

- 오프닝 다음 구간에 2pane 소개 섹션이 표시된다. 왼쪽은 "Hello! I'm {역할} 이정준"과 역할별 한 줄 소개, 오른쪽은 같은 비율(4:5) 역할 사진 2×2다.
- 역할이 4초마다 Educator → Developer → Artist → Entrepreneur 순으로 자동 순환하고, 선택된 사진만 컬러로, 나머지는 흑백으로 표시된다.
- 사용자가 사진을 눌러 역할을 고르면 순환이 멈추고, 멈춤/재생 버튼으로 순환을 멈추거나 다시 시작할 수 있다.
- 섹션이 화면 밖에 있거나 탭이 숨겨지면 순환이 멈추고, `prefers-reduced-motion` 사용자에게는 자동 순환 없이 첫 역할이 선택된 상태로 표시된다.
- 프리렌더된 `dist/index.html`에 네 역할의 이름과 한 줄 소개가 모두 포함된다.
- 기존 정체성 섹션(카드 4개)이 이 섹션으로 대체된다.

## 구현 상세

### 레이아웃

```
┌─────────────────────────────┬──────────────────────────────┐
│  Hello! I'm                 │  ┌─────────┐  ┌─────────┐    │
│  Educator          ← 순환    │  │ (컬러)   │  │ (흑백)   │    │
│  이정준                      │  │ ▬▬▬──   │  └─────────┘    │
│                             │  └─────────┘                 │
│  한 줄 소개                   │  ┌─────────┐  ┌─────────┐    │
│                     [ ❚❚ ]  │  │ (흑백)   │  │ (흑백)   │    │
│                             │  └─────────┘  └─────────┘    │
└─────────────────────────────┴──────────────────────────────┘
```

- 데스크톱(`md` 이상): 좌우 2pane. 왼쪽은 큰 세리프 타이포, 오른쪽은 2×2 그리드.
- 모바일: 위에 글, 아래에 2×2 그리드. 진행 막대는 사진이 작아지므로 글 쪽(역할 단어 아래)에 둔다.
- 사진 칸에는 역할 이름 라벨을 작게 붙인다(선택하지 않은 칸에서도 어떤 역할인지 보이게).

### 상태와 동작

상태는 `activeIndex`, `isPinned`(사용자가 클릭으로 고정), `isPaused`(멈춤 버튼), `isHovering`, `isInView`, `isDocumentVisible`이다. 순환은 `!isPinned && !isPaused && !isHovering && isInView && isDocumentVisible && !reducedMotion`일 때만 진행한다.

| 입력 | 동작 |
|------|------|
| 4초 경과 | 다음 역할로 전환. 선택 사진 아래 진행 막대가 4초 동안 차오름 |
| 사진 클릭·탭 | 그 역할로 전환, `isPinned = true` (순환 정지) |
| 사진에 마우스 올림 (hover 가능한 기기만) | 그 역할을 미리 보여주고 일시정지. 떠나면 고정 상태가 아니면 원래 순환으로 복귀 |
| 멈춤/재생 버튼 | `isPaused` 토글. 고정 상태에서 재생을 누르면 고정 해제 후 순환 재개 |
| 키보드 | 사진 칸은 `button`. Tab으로 이동, Enter/Space로 선택(클릭과 동일) |
| 섹션 화면 이탈 / 탭 숨김 | 순환 정지, 복귀 시 재개 (`IntersectionObserver`, `visibilitychange`) |

- 진행 막대는 Motion으로 `scaleX` 0→1 애니메이션하고, 일시정지 시 그 자리에서 멈췄다가 재개 시 이어서 진행한다.
- 역할 단어 전환은 기존 사이트처럼 위로 밀려 올라가는 교체(`AnimatePresence` + `y`/`opacity`), 한 줄 소개는 opacity 교차 전환이다.
- 사진 상태 전환: 비선택 `grayscale(1)` + 낮은 opacity, 선택 시 컬러 + 원래 opacity. `filter` 전환은 칸 4개뿐이라 허용한다.
- `prefers-reduced-motion`: 자동 순환 없음, 멈춤 버튼 숨김, 전환은 즉시 교체.

### 접근성·SEO

- 자동 순환 중에는 문구 영역에 `aria-live="off"`, 사용자가 직접 고른 직후에만 `aria-live="polite"`로 바뀐 역할을 읽게 한다.
- 멈춤/재생 버튼은 `aria-pressed`와 상태에 맞는 `aria-label`을 가진다(WCAG 2.2.2).
- 네 역할의 한 줄 소개는 모두 DOM에 렌더하고 비활성 문구는 시각적으로만 숨긴다(`display: none` 금지). 프리렌더 HTML에서 검색엔진이 모두 읽을 수 있다.
- 사진 `alt`는 "교육자 이정준" 형식. 섹션 제목은 '이정준' `h1`이 오프닝에 있으므로 `h2`로 둔다.
- SSR과 첫 hydration 결과가 같도록 초기 `activeIndex = 0`, 순환은 마운트 후 effect에서 시작한다.

### 자산

원본은 `asset/intro/`(gitignore)에 있고, 스크립트로 4:5 크롭 + AVIF/WebP(폭 400/800)를 생성해 `profile/src/assets/intro/`에 커밋한다. 흑백 처리는 CSS로 하므로 컬러 원본만 만든다.

| 역할 | 원본 | 크기 | 크롭 |
|------|------|------|------|
| Educator | `educator.jpg` (책을 든 셀카) | 1107×1384 | 거의 4:5. 얼굴 중심 소폭 조정 |
| Developer | `developer.jpg` (푸드트럭 앞) | 1207×903 | 가로 사진에서 인물 중심 세로 크롭(약 722×903). 인물이 작아 800폭 출력은 확대가 되므로 출력 최대 폭을 원본 크롭 폭 이하로 제한 |
| Artist | `artist.jpg` (만화 벽화 앞, 걷는 뒷모습) | 2919×2280 | 인물과 벽화를 함께 담는 세로 크롭 |
| Entrepreneur | `entrepreneur.jpg` (넥타이 셀카) | 1080×1440 | 3:4 → 4:5, 위아래 소폭 크롭 |

- 크롭 좌표는 스크립트 상수로 두고, 네 장을 2×2로 붙인 미리보기를 스크래치 경로에 출력해 사용자 확인 후 확정한다.
- 사진 톤 통일(밝기·대비)은 필요하면 스크립트에서 보정한다. 기본은 원본 색 유지 + CSS 흑백.
