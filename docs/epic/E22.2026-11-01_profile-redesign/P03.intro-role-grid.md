# P03: 소개 역할 벤토

## 목표

- 오프닝 다음 구간에 소개 섹션이 표시된다. 왼쪽에는 진행선 위쪽에 정렬된 재생/일시정지 버튼, 역할 탭 4개, "Hello! I'm {역할} 이정준", 역할별 짧은 사실 한 줄이 놓이고 오른쪽에는 역할 사진 2×2 벤토가 있다.
- 네 사진은 Educator 왼쪽 위부터 시계방향으로 고정된다. 하나의 세로 분할선과 열마다 독립적인 가로 분할선이 움직여 활성 역할의 칸을 키운다. 활성 사진은 컬러, 나머지 세 칸은 흑백이다.
- 역할이 3초마다 Educator → Entrepreneur → Artist → Developer 순으로 자동 순환하고, 활성 탭의 밑줄이 진행 막대로 차오른다.
- 사용자는 역할 탭과 재생/일시정지 버튼으로 역할을 고르거나 순환을 멈추고 이어서 재생할 수 있다. 사진은 클릭할 수 없다.
- 섹션이 화면 밖에 있거나 탭이 숨겨지면 순환이 멈추고, `prefers-reduced-motion` 사용자는 일시정지 상태로 시작하며 분할선·사진 크롭 애니메이션이 없다.
- 프리렌더된 `dist/index.html`에 네 역할의 이름과 사실 한 줄이 모두 포함된다.
- 기존 정체성 섹션(카드 4개)이 이 섹션으로 대체된다.

## 구현 상세

### 레이아웃

**데스크톱** (`md` 이상)

```
──────────────────────────────────────────────────────────── ← 얇은 구분선
 Educator    Entrepreneur    Artist    Developer          ❚❚  ← 역할 탭 + 재생/일시정지
 ▬▬▬▬──                                                       ← 활성 탭 밑줄 = 진행 막대
┌───────────────────────────┬──────────────────────────────┐
│  Hello! I'm               │  ┌───────────────┬──────┐     │
│  Educator        ← 바뀜    │  │               │ Ent  │     │
│  이정준                    │  │   Educator    │      │     │
│  고등학교 국어교사,          │  │               ├──────┤     │
│  코딩교육         ← 바뀜    │  │               │ Art  │     │
│  야망솔루션 대표   ← 설명   │  ├───────────────┤      │     │
│                           │  │     Dev       │      │     │
│                           │  └───────────────┴──────┘     │
└───────────────────────────┴──────────────────────────────┘
```

- 섹션 위에 화면 높이 10~15%의 여백을 둔다. 오프닝 섹션이 끝난 뒤 새 섹션이 시작된다는 느낌을 주기 위해서다. 그 아래 얇은 구분선과 탭 줄이 섹션 머리 역할을 한다.
- 오프닝과 이 섹션 사이는 일반 스크롤로 넘어간다. 화면 고정·스크롤 스냅·스크롤 연동 변형은 쓰지 않는다.
- **진입 등장**: 섹션이 처음 화면에 들어오면 탭 줄 → 문구 → 벤토 순으로 아래에서 살짝 올라오며 페이드인한다(초기값 `y: 24px → 0`, `opacity: 0 → 1`, 0.6초 `easeOut`, 요소 간 0.1초 간격). 바깥 tabpanel에는 등장 애니메이션을 중복 적용하지 않는다. 한 번만 재생한다. 프리렌더 HTML에는 최종 상태로 두고, 하이드레이션 후 화면 밖에 있는 경우에만 숨김 상태에서 시작해 깜빡임과 콘텐츠 숨김을 피한다. 벤토 등장 애니메이션의 완료 이벤트로 순환을 시작하며 시간을 하드코딩하지 않는다. `prefers-reduced-motion`에서는 등장 연출 없이 바로 보인다.
- 재생/일시정지 버튼은 역할 탭 왼쪽의 진행선과 중심을 맞춰 첫 탭 위에 둔다. 숫자 표시(01/04 등)는 두지 않는다.
- 벤토 상단에 맞춰 왼쪽 역할 목록을 놓고, 활성 역할의 설명을 목록 바로 아래에 표시한다. 모바일 순서는 재생/일시정지 버튼 → 역할 목록 → 설명 → 벤토다.
- 벤토는 데스크톱·태블릿에서 오른쪽 콘텐츠 칸의 75% 너비로 중앙 정렬하고, 모바일에서는 칸 너비 전체를 사용한다.

**모바일**

```
Educator  Entrepreneur  Artist  Developer   ❚❚   ← 넘치면 가로 스크롤
▬▬▬▬──
Hello! I'm / Educator / 이정준
고등학교 국어교사, 코딩교육
┌──────────────┬──────┐
│   2×2 벤토    │      │   ← 화면 폭에 맞춘 같은 구조
├──────────────┤      │
└──────────────┴──────┘
```

### 벤토: 분할선이 움직이는 2×2

| 사분면 | 역할 | 원본 | 비율 r (가로/세로) |
|------|------|------|------|
| 왼쪽 위 | Educator | `featured_activity_education.jpg` 1440×1080 | 1.33 |
| 오른쪽 위 | Entrepreneur | `entrepreneur.jpg` 1080×1440 | 0.75 |
| 오른쪽 아래 | Artist | `artist.jpg` 2919×2280 | 1.28 |
| 왼쪽 아래 | Developer | `developer.jpg` 1207×903 | 1.34 |

Educator 사진은 주요 활동의 `featured_activity_education.jpg`를 사용한다. 원본은 `asset/intro/educator.jpg`로 복사하고, 원본 크기는 1440×1080, 비율은 1.33이다.

- 각 사진은 위 표의 사분면 위치에 고정되고, 활성 역할이 바뀌어도 자리를 바꾸지 않는다.
- 벤토 컨테이너 비율은 초기값 1:1이다(데스크톱·모바일 공통).
- **활성 칸 크기**: 활성 칸의 짧은 변이 정사각 컨테이너의 50%를 차지하고, 긴 변은 해당 원본 비율 r로 정한다. 비율은 `r = 활성 칸 가로 / 활성 칸 세로`다.

  | 활성 역할 | 활성 칸 가로 | 활성 칸 세로 |
  |------|------|------|
  | Educator | 약 66.7% | 50% |
  | Entrepreneur | 50% | 약 66.7% |
  | Artist | 약 64% | 50% |
  | Developer | 약 66.8% | 50% |

- 가로 분할선은 왼쪽·오른쪽 열마다 독립적이다. 활성 역할이 있는 열은 원본 비율에 맞춰 움직이고, 비활성 열은 아래 표의 역할별 분할값을 쓴다. 두 가로선은 18% 이상 떨어져 있으며 모든 순환 전환에서 적어도 하나의 분할선이 12% 이상 움직인다.

  | 활성 역할 | x | 왼쪽 열 y | 오른쪽 열 y | 가로선 차이 |
  |------|------:|------:|------:|------:|
  | Educator | 66.7% | 50% | 68% | 18% |
  | Entrepreneur | 50.0% | 48% | 66.7% | 약 18.7% |
  | Artist | 36.0% | 32% | 50% | 18% |
  | Developer | 66.8% | 50% | 80% | 30% |

  - Educator → Entrepreneur → Artist → Developer 순환에서 세 분할값의 한 바퀴 이동 거리는 총 약 157.7%다.
- **칸 사이 간격**: 초기값 8px.
- **활성 칸**: 컬러로 보이고 사진을 늘리지 않는다.
- **나머지 칸**: `object-fit: cover`로 인물 초점에 맞춰 확대 크롭하고, `grayscale(1)`과 약간 낮은 opacity로 표시한다. 활성화되면 장면 초점으로 이동하며 1배 크기로 돌아온다.
- 칸에는 역할 이름 라벨을 작게 붙인다.

**구현 방식**
- `introAssets.ts`가 역할 id별 원본 비율을 소유한다. `bentoLayout.ts`는 활성 역할 id만 받아 `{ x, yLeft, yRight }` 분할값을 계산한다.
- 두 열을 CSS flex 레이아웃으로 배치한다. `@property`로 등록한 분할값을 애니메이션하고, `contain: layout paint`로 레이아웃·페인트 범위를 벤토 안에 둔다. 간격은 고정 8px이다.
- 세로 분할선은 0.5초 `ease-in-out`으로 먼저 움직인다. 두 가로 분할선은 0.25초 뒤 시작해 세로 전환과 0.25초 겹친다.
- 사진은 항상 `object-fit: cover`를 사용한다. 비활성 상태에서 인물 초점·역할별 줌을 쓰고, 활성 상태에서는 장면 초점·1배 크기로 전환한다. `object-position`도 애니메이션해 인물에서 장면으로 부드럽게 이동한다.
- 흑백 `filter`는 활성 상태 변경 시 즉시 적용하고 보간하지 않는다. 분할선·초점·확대·불투명도 전환은 유지한다. 레이아웃 전환 자체의 모바일 비용은 브라우저에서 별도 측정한다.
- `prefers-reduced-motion: reduce`에서는 분할선과 사진 크롭 전환을 끈다.

### 왼쪽 문구

- 바뀌는 것: 역할 단어와 짧은 사실 한 줄. 고정: "Hello! I'm", "이정준".
- 기존 정체성 카드의 긴 소개 문장과 태그라인은 쓰지 않는다. 3초 안에 읽히지 않고 벤토 전환과 시선이 겹치기 때문이다.

  | 역할 | 사실 한 줄 |
  |------|------|
  | Educator | 고등학교 국어교사, 코딩교육 |
  | Entrepreneur | 야망솔루션 대표 |
  | Artist | 성균관대 순수미술 동아리 성미회 |
  | Developer | ERP · WEB 개발 및 운영 |

- 역할 단어는 위로 밀려 올라가며 교체(`AnimatePresence` + `y`/`opacity`), 사실 한 줄은 opacity 교차 전환이다.
- 네 역할의 문구는 모두 DOM에 두고 비활성 문구는 시각적으로만 숨긴다(`display: none` 금지).

### 컨트롤과 재생 규칙

**구성**
- 역할 탭 4개, 재생/일시정지 버튼 1개.
- 활성 탭의 밑줄이 진행 막대다. 3초 동안 `scaleX` 0→1로 차오른다.

**상태**
- 사용자가 정한 상태 `playState: 'playing' | 'paused'`
- 현재 역할 진행도 `progress`(0~1)
- 시스템이 잠시 멈추는 조건 `isSuspended = !isInView || !isDocumentVisible || isTabListFocused`
- 실제 진행 여부: `playState === 'playing' && !isSuspended`

| 상황 | 동작 | 진행 막대 |
|------|------|------|
| 섹션이 처음 화면에 들어옴 | 진입 등장이 끝난 뒤 재생 시작 | 0%부터. 첫 역할도 3초를 온전히 보여줌 |
| 3초 경과 | 다음 역할로. 마지막 다음은 첫 역할로 반복 | 새 역할 0%부터 |
| 일시정지 버튼 | `paused` | 그 자리에서 멈춤 |
| 역할 탭 클릭 | 그 역할로 바꾸고 `paused` | 0%에서 멈춤 |
| 재생 버튼 | `playing`, 현재 역할에서 이어서 재생 | 멈춘 지점부터 이어서 진행 |
| 화면 밖으로 스크롤 / 다른 탭으로 이동 | 잠시 멈춤 | 그 자리에서 멈춤 |
| 다시 돌아옴 | `playing`이었으면 이어서 재생 | 멈춘 지점부터 |
| 키보드 포커스가 탭 줄에 들어옴 | 잠시 멈춤, 나가면 원래 상태로 | 그 자리에서 멈춤 |
| 벤토·문구 위에 마우스 올림 | 아무 동작 없음 | 영향 없음 |

- 진행도는 `requestAnimationFrame` 경과 시간으로 누적한다(멈춘 동안 누적하지 않음). 막대는 `progress` 값을 `scaleX`로 표시하는 Motion value로 연결해, 리렌더 없이 갱신한다.
- `prefers-reduced-motion`: `paused`로 시작한다. 재생 버튼은 보이며, 재생하면 순환하되 분할선과 사진 크롭은 애니메이션 없이 즉시 바뀐다(`MotionConfig reducedMotion="user"`). 진행 막대는 유지한다.

### 접근성·SEO

- 웹 접근성 지침의 **자동 회전 탭 패턴**을 따른다.
  - 탭 줄은 `role="tablist"`, 역할 버튼은 `role="tab"` + `aria-selected` + `aria-controls`, 문구와 벤토를 감싼 영역은 `role="tabpanel"`이다.
  - 키보드 좌우 화살표로 탭 이동, Home/End로 처음·끝 탭. 화살표로 탭을 옮기면 그 역할로 바뀌고 `paused`가 된다(클릭과 동일).
  - 재생/일시정지 버튼은 탭 줄 바깥의 `button`이며, 상태에 맞는 `aria-label`("자동 전환 정지" / "자동 전환 재생")을 가진다(WCAG 2.2.2).
- 자동 순환 중에는 tabpanel에 `aria-live="off"`, 일시정지 상태에서는 `aria-live="polite"`로 둔다.
- 사진 `alt`는 "교육자 이정준" 형식이다. 화면에 보이는 '이정준'을 페이지의 `h1`로 둔다. 이때 P02 오프닝에 있는 시각적으로 숨긴 `h1`("이정준")을 제거해 `h1`이 하나만 남게 한다.
- SSR과 첫 hydration 결과가 같도록 초기 `activeIndex = 0`, `progress = 0`으로 두고, 순환은 마운트 후 화면 진입 시 시작한다.

### 자산

원본은 `asset/intro/`(gitignore)에 있다. `profile/scripts/build-intro-assets.mjs`(`package.json`에 `assets:intro`로 등록, `build`에 넣지 않음)가 AVIF/WebP를 생성해 `profile/src/assets/intro/`에 출력하고, 결과물을 커밋한다.

- 생성 자산은 원본 비율을 유지해 리사이즈한다. 화면에서는 모든 칸에 `object-fit: cover`를 적용하고, 활성 칸은 장면 초점으로 표시한다. 흑백은 CSS로 처리하므로 컬러 원본만 만든다.
- 출력 폭은 400 / 800 / 1200이며 원본 폭을 넘지 않는다(Developer는 1207, Entrepreneur는 1080이 상한). 칸 크기가 바뀌므로 `sizes`는 활성 칸 최대 크기 기준으로 잡는다.
- 역할 사진 4장은 `loading="lazy"`로 두고 원본 비율에 맞는 `width`·`height`를 제공한다. `sizes`는 데스크톱에서 `min(30.4vw, 25.6rem)`으로 제한하며, 모바일은 좌우 여백을 뺀 벤토의 최대 활성 칸 폭(78%)을 기준으로 한다.
