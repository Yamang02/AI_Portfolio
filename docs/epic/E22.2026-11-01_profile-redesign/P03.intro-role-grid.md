# P03: 소개 역할 벤토

## 목표

- 오프닝 다음 구간에 소개 섹션이 표시된다. 섹션 머리에 역할 탭 4개와 재생/일시정지 버튼, 그 아래 왼쪽에 "Hello! I'm {역할} 이정준"과 역할별 짧은 사실 한 줄, 오른쪽에 역할 사진 2×2 벤토가 있다.
- 네 사진은 각자 사분면에 고정되고, 2×2를 나누는 교차점이 움직여 활성 역할의 칸이 그 사진의 원본 비율 그대로 크게 표시된다. 활성 사진은 컬러, 나머지 세 칸은 흑백이다.
- 역할이 4초마다 Educator → Developer → Artist → Entrepreneur 순으로 자동 순환하고, 활성 탭의 밑줄이 진행 막대로 차오른다.
- 사용자는 역할 탭과 재생/일시정지 버튼으로 역할을 고르거나 순환을 멈추고 이어서 재생할 수 있다. 사진은 클릭할 수 없다.
- 섹션이 화면 밖에 있거나 탭이 숨겨지면 순환이 멈추고, `prefers-reduced-motion` 사용자는 일시정지 상태로 시작하며 교차점 이동 애니메이션이 없다.
- 프리렌더된 `dist/index.html`에 네 역할의 이름과 사실 한 줄이 모두 포함된다.
- 기존 정체성 섹션(카드 4개)이 이 섹션으로 대체된다.

## 구현 상세

### 레이아웃

**데스크톱** (`md` 이상)

```
──────────────────────────────────────────────────────────── ← 얇은 구분선
 Educator    Developer    Artist    Entrepreneur          ❚❚  ← 역할 탭 + 재생/일시정지
 ▬▬▬▬──                                                       ← 활성 탭 밑줄 = 진행 막대
┌───────────────────────────┬──────────────────────────────┐
│  Hello! I'm               │  ┌───────────────┬──────┐     │
│  Educator        ← 바뀜    │  │               │ Dev  │     │
│  이정준                    │  │   Educator    │      │     │
│  고등학교 국어교사 ·          │  │  (원본 비율)    ├──────┤     │
│  바이브코딩 과외   ← 바뀜    │  │               │ Ent  │     │
│                           │  ├───────────────┤      │     │
│                           │  │     Art       │      │     │
│                           │  └───────────────┴──────┘     │
└───────────────────────────┴──────────────────────────────┘
```

- 섹션 위에 화면 높이 10~15%의 여백을 둔다. 오프닝 고정 구간이 끝난 뒤 새 섹션이 시작된다는 느낌을 주기 위해서다. 그 아래 얇은 구분선과 탭 줄이 섹션 머리 역할을 한다.
- 탭 줄 오른쪽 끝, 벤토 오른쪽 위와 맞닿는 자리에 재생/일시정지 버튼을 둔다. 숫자 표시(01/04 등)는 두지 않는다.
- 왼쪽 문구 아래 2pane, 오른쪽 벤토.

**모바일**

```
├──────────────┤      │
└──────────────┴──────┘
```

### 벤토: 교차점이 움직이는 2×2

| 사분면 | 역할 | 원본 | 비율 r (가로/세로) |
|------|------|------|------|
| 왼쪽 위 | Educator | `educator.jpg` 1107×1384 | 0.80 |
| 오른쪽 위 | Developer | `developer.jpg` 1207×903 | 1.34 |
| 왼쪽 아래 | Artist | `artist.jpg` 2919×2280 | 1.28 |
| 오른쪽 아래 | Entrepreneur | `entrepreneur.jpg` 1080×1440 | 0.75 |

- 사진은 사분면 위치를 바꾸지 않는다.
- 벤토 컨테이너 비율은 초기값 1:1이다(데스크톱·모바일 공통).
- **활성 칸 크기**: 활성 칸의 짧은 변이 컨테이너의 60%를 차지하고, 긴 변은 원본 비율 r로 정한다. 비율은 `r = 활성 칸 가로 / 활성 칸 세로`이고, 컨테이너가 1:1이 아니면 컨테이너 비율을 반영해 계산한다.

  | 활성 역할 | 활성 칸 가로 | 활성 칸 세로 |
  |------|------|------|
  | Educator | 60% | 75% |
  | Developer | 80% | 60% |
  | Artist | 77% | 60% |
  | Entrepreneur | 60% | 80% |

- **교차점 위치**: 활성 칸이 차지하는 쪽으로 정해진다. 예를 들어 Educator가 활성이면 교차점은 (60%, 75%), Entrepreneur가 활성이면 (40%, 20%)다.
- **이동 범위 제한**: 교차점은 가로·세로 각각 20~80% 안으로 제한한다. 계산값이 범위를 넘으면 범위 안으로 자르고, 그때는 활성 칸이 원본 비율에서 조금 벗어나며 그만큼 잘린다. 작아진 칸이 너무 얇아지지 않고, 각 사진의 중심이 자기 사분면을 크게 벗어나지 않게 하기 위해서다.
- **칸 사이 간격**: 초기값 8px.
- **활성 칸**: 원본 비율 그대로라 사진 전체가 컬러로 보인다.
- **나머지 칸**: `object-fit: cover` + 역할별 `object-position`(초점 좌표)으로 잘려 보이고, `grayscale(1)`과 약간 낮은 opacity다.
- 칸에는 역할 이름 라벨을 작게 붙인다.

**구현 방식**
- `bentoLayout.ts`가 `(activeIndex, containerAspect, ratios)` → 교차점 `(x, y)` → 네 칸의 사각형(%)을 계산한다. 이 계산은 순수 함수로 둔다.
- 네 칸은 컨테이너 안에 `position: absolute`로 % 좌표 배치하고, Motion `layout` 애니메이션(FLIP)으로 이동한다. 칸 래퍼와 그 안의 이미지 래퍼 모두에 `layout`을 주어, 칸 크기가 바뀌는 동안 사진이 늘어나 보이지 않게 한다(Motion scale correction). 라벨은 `layout="position"`이다.
- 칸 `key`는 역할 id로 고정한다.
- 교차점 이동 시간은 초기값 0.7초, `easeInOut`이다.
- 대안으로 CSS `grid-template-columns/rows` 전환도 가능하지만, 매 프레임 레이아웃을 다시 계산하므로 transform 기반인 `layout`을 우선한다. 모바일 4x CPU 감속에서 끊기면 그때 비교한다.

### 왼쪽 문구

- 바뀌는 것: 역할 단어와 짧은 사실 한 줄. 고정: "Hello! I'm", "이정준".
- 기존 정체성 카드의 긴 소개 문장과 태그라인은 쓰지 않는다. 4초 안에 읽히지 않고 벤토 전환과 시선이 겹치기 때문이다.

  | 역할 | 사실 한 줄 |
  |------|------|
  | Educator | 고등학교 국어교사 · 바이브코딩 과외 |
  | Developer | ERP · WEB 개발 및 운영 |
  | Artist | 성균관대 순수미술 동아리 성미회 |
  | Entrepreneur | 야망솔루션 대표 |

- 역할 단어는 위로 밀려 올라가며 교체(`AnimatePresence` + `y`/`opacity`), 사실 한 줄은 opacity 교차 전환이다.
- 네 역할의 문구는 모두 DOM에 두고 비활성 문구는 시각적으로만 숨긴다(`display: none` 금지).

### 컨트롤과 재생 규칙

**구성**
- 역할 탭 4개, 재생/일시정지 버튼 1개.
- 활성 탭의 밑줄이 진행 막대다. 4초 동안 `scaleX` 0→1로 차오른다.

**상태**
- 사용자가 정한 상태 `playState: 'playing' | 'paused'`
- 현재 역할 진행도 `progress`(0~1)
- 시스템이 잠시 멈추는 조건 `isSuspended = !isInView || !isDocumentVisible || isTabListFocused`
- 실제 진행 여부: `playState === 'playing' && !isSuspended`

| 상황 | 동작 | 진행 막대 |
|------|------|------|
| 섹션이 처음 화면에 들어옴 | 그때부터 재생 시작 | 0%부터. 첫 역할도 4초를 온전히 보여줌 |
| 4초 경과 | 다음 역할로. 마지막 다음은 첫 역할로 반복 | 새 역할 0%부터 |
| 일시정지 버튼 | `paused` | 그 자리에서 멈춤 |
| 역할 탭 클릭 | 그 역할로 바꾸고 `paused` | 0%에서 멈춤 |
| 재생 버튼 | `playing`, 현재 역할에서 이어서 재생 | 멈춘 지점부터 이어서 진행 |
| 화면 밖으로 스크롤 / 다른 탭으로 이동 | 잠시 멈춤 | 그 자리에서 멈춤 |
| 다시 돌아옴 | `playing`이었으면 이어서 재생 | 멈춘 지점부터 |
| 키보드 포커스가 탭 줄에 들어옴 | 잠시 멈춤, 나가면 원래 상태로 | 그 자리에서 멈춤 |
| 벤토·문구 위에 마우스 올림 | 아무 동작 없음 | 영향 없음 |

- 진행도는 `requestAnimationFrame` 경과 시간으로 누적한다(멈춘 동안 누적하지 않음). 막대는 `progress` 값을 `scaleX`로 표시하는 Motion value로 연결해, 리렌더 없이 갱신한다.
- `prefers-reduced-motion`: `paused`로 시작한다. 재생 버튼은 보이며, 재생하면 순환하되 교차점은 애니메이션 없이 즉시 바뀐다(`MotionConfig reducedMotion="user"`). 진행 막대는 유지한다.

### 접근성·SEO

- 웹 접근성 지침의 **자동 회전 탭 패턴**을 따른다.
  - 탭 줄은 `role="tablist"`, 역할 버튼은 `role="tab"` + `aria-selected` + `aria-controls`, 문구와 벤토를 감싼 영역은 `role="tabpanel"`이다.
  - 키보드 좌우 화살표로 탭 이동, Home/End로 처음·끝 탭. 화살표로 탭을 옮기면 그 역할로 바뀌고 `paused`가 된다(클릭과 동일).
  - 재생/일시정지 버튼은 탭 줄 바깥의 `button`이며, 상태에 맞는 `aria-label`("자동 전환 정지" / "자동 전환 재생")을 가진다(WCAG 2.2.2).
- 자동 순환 중에는 tabpanel에 `aria-live="off"`, 일시정지 상태에서는 `aria-live="polite"`로 둔다.
- 사진 `alt`는 "교육자 이정준" 형식이다. 섹션 제목은 오프닝에 '이정준' `h1`이 있으므로 시각적으로 숨긴 `h2`("소개")로 둔다.
- SSR과 첫 hydration 결과가 같도록 초기 `activeIndex = 0`, `progress = 0`으로 두고, 순환은 마운트 후 화면 진입 시 시작한다.

### 자산

원본은 `asset/intro/`(gitignore)에 있다. `profile/scripts/build-intro-assets.mjs`(`package.json`에 `assets:intro`로 등록, `build`에 넣지 않음)가 AVIF/WebP를 생성해 `profile/src/assets/intro/`에 출력하고, 결과물을 커밋한다.

- 활성 칸은 원본 비율 그대로이므로 **원본 비율을 유지한 채** 리사이즈만 한다(자르지 않음). 흑백은 CSS로 처리하므로 컬러 원본만 만든다.
- 출력 폭은 400 / 800 / 1200이며 원본 폭을 넘지 않는다(Developer는 1207, Entrepreneur는 1080이 상한). 칸 크기가 바뀌므로 `sizes`는 활성 칸 최대 크기 기준으로 잡는다.
- 초점 좌표는 `content.json`의 `focus`(예: `"50% 30%"`)로 둔다. 작은 칸에서 잘려 보일 때의 중심이며, 사용자가 화면을 보며 정한다. 초기값은 Educator·Entrepreneur는 얼굴, Developer·Artist는 인물 위치다.
