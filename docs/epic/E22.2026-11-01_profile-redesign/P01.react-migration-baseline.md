# P01: React 전환 정비

## 목표

- `profile`이 pnpm + 최신 의존성(React 19.3, Vite 8, TypeScript 7, Tailwind 4.3, Motion 14)으로 설치·빌드된다.
- 페이지가 React 컴포넌트로 렌더링되며, 화면·문구·인터랙션(로고 순환, 역할 순환, 스크롤 스파이, 활동 모달 3종, 연락 모달 + EmailJS 전송, ESC/오버레이 닫기)이 전환 전과 동일하다.
- `pnpm build` 결과 `dist/index.html`에 본문 HTML이 프리렌더되어 포함된다.
- 콘텐츠는 `src/content/content.json` 하나에서 공급되고 git에 추적된다.
- staging/production 배포 워크플로 설정이 Node 22 + pnpm 기준으로 바뀐다. 원격 실행과 배포 환경 확인은 로컬 개발이 끝난 뒤 에픽 마지막 배포 정비에서 한다(Readme `## 후속`).

## 구현 상세

### 접근

1. **툴체인 교체**: `package-lock.json` 제거, `packageManager` 필드로 pnpm 버전 고정, 의존성을 최신으로 재설치. Tailwind는 `@tailwindcss/vite` 플러그인 + CSS `@theme`으로 기존 `tailwind.config` 토큰(색상, borderRadius 오버라이드, fontFamily)을 그대로 옮긴다.
2. **콘텐츠/타입**: E13 타입(git `02620e8^:profile/src/types/profile.ts`)을 복원해 현재 `content.json`과 대조·보정한다. 하이라이트 카드의 `period`처럼 HTML 배열에만 있는 필드는 JSON에 추가한다.
3. **컴포넌트 분해**: 섹션 단위로 분리한다. 마크업·클래스는 기존 HTML을 그대로 옮기되, 런타임 문자열 보간 클래스(`md:col-span-${n}`, `min-h-[${n}px]`)는 정적 클래스 매핑 또는 inline style로 바꾼다. 아무 CSS도 생성하지 않던 `rounded-DEFAULT`는 제거해 결과를 동일하게 유지한다.
4. **인터랙션**: `innerHTML`/전역 함수를 React state로 교체한다. 로고 순환·스크롤 스파이는 `useEffect`, 모달 열림 시 `body` 스크롤 잠금과 ESC 닫기는 공용 훅으로 묶는다. HTML 문자열이 들어 있는 `body`(`<br>` 포함)는 `dangerouslySetInnerHTML`로 렌더한다(정적 자체 콘텐츠).
5. **EmailJS**: CDN 스크립트 + `%VITE_*%` 치환을 `@emailjs/browser` 패키지 + `import.meta.env.VITE_*`로 교체한다. 전송 파라미터·검증 규칙·alert 문구는 유지한다.
6. **프리렌더**: `src/entry-client.tsx`(`hydrateRoot`) / `src/entry-server.tsx`(`renderToString`)로 분리하고, `index.html`의 `<div id="root"><!--app-html--></div>` 자리에 빌드 후 스크립트가 SSR 결과를 주입한다. `<head>`(SEO 메타, GA, 폰트 링크)는 `index.html`에 그대로 둔다.
7. **Motion**: 의존성 설치 + 앱 루트에 `MotionConfig reducedMotion="user"`만 둔다. 애니메이션 적용은 후속 Phase에서 한다.
8. **CI**: 두 워크플로에 `pnpm/action-setup` 추가, Node 22, `pnpm install --frozen-lockfile`, 캐시 경로를 `pnpm-lock.yaml`로 변경.
