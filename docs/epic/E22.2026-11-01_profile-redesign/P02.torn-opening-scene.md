# P02: 찢김 오프닝 장면

## 목표

- 첫 화면에 hero.jpg와 같은 띠 3개 형태로 나뉜 〈타락천사〉가 표시되고, 스크롤하면 각 띠가 종이처럼 찢겨 걷히며 같은 자리에 hero.jpg 띠가 드러난다.
- 찢김 진행은 스크롤에 연동되어, 위로 스크롤하면 조각이 다시 맞물려 〈타락천사〉로 돌아간다.
- 가운데 눈 띠가 가장 늦게 찢겨, 루시퍼의 눈이 이정준의 눈으로 바뀌는 순간이 장면의 정점이 된다.
- hero가 완전히 드러난 뒤 위 띠에 '야망솔루션', 아래 띠에 '이정준'이 이미지 위로 나타난다.
- 데스크톱(1440px)과 모바일(390px) 모두에서 같은 연출이 끊김 없이 동작하고, `prefers-reduced-motion` 사용자에게는 찢김 없이 축소된 전환이 표시된다.
- 프리렌더된 `dist/index.html`에 '이정준' `h1`과 '야망솔루션' 텍스트가 포함되고, 모바일 Lighthouse LCP가 2.5초 이하다.

## 착수 전 확인 (구현 에이전트용)

- **P01이 커밋된 뒤 시작한다.** P01은 같은 작업 트리에서 진행 중이며 `profile/src/` 전체가 아직 미커밋 상태다. `git log`에 P01 커밋이 있고 `git status`에 `profile/src/`가 미추적으로 남아 있지 않은지 먼저 확인한다.
- **컨셉 배경**은 에픽 [Readme](./Readme.md) `## 특이점`의 "명함" 구성과 모션 원칙을 읽는다. 이 장면은 페이지에서 유일하게 화면을 고정하는 큰 연출이다.
- **파일 네이밍은 기존 `profile/src` 관례를 따른다.** 컴포넌트는 PascalCase 파일(`OpeningScene.tsx`), 훅은 camelCase(`useScrollSpy.ts`)다.
- **원본 자산 `asset/`는 수정·이동하지 않는다.** gitignore 대상이며 CI에는 없다. 생성 스크립트 결과물만 커밋한다.
- **인라인 주석을 추가하지 않는다**(사용자 선호). 이름과 구조로 의도를 드러낸다.
- 명령은 `profile/`에서 실행한다: `pnpm dev`, `pnpm typecheck`, `pnpm build`, `pnpm preview`.

## 구현 상세

### 장면 구성

- 섹션 높이 `250svh`. 안쪽 래퍼는 `sticky top-0 h-svh`이고 그 가운데에 정사각형 액자를 둔다.
- 액자 크기는 `min(100vw - 32px, 100svh - 176px)`로 시작한다. 고정 Nav(약 88px) 아래에서 액자가 잘리지 않게 하는 값이며, 실제 화면을 보고 조정한다.
- 오프닝은 `main`의 첫 자식이다. 현재 `main`의 `pt-32`는 오프닝이 Nav 높이를 스스로 감안하므로 제거한다.
- 액자 배경은 hero.jpg의 틈·여백 색인 순백 `#ffffff`다(실측 255,255,255). 이 위에 띠를 % 좌표로 배치하면 틈과 여백이 자연스럽게 생긴다.
- 진행도는 섹션 기준 `useScroll({ target, offset: ['start start', 'end end'] })`의 `scrollYProgress`(0→1)다.

| 진행도 | 상태 |
|------|------|
| 0 | 띠 3개로 나뉜 〈타락천사〉 전체 |
| 0.05–0.35 | 위 띠(머리칼) 찢김 → hero 머리 띠 노출 |
| 0.20–0.50 | 아래 띠(팔) 찢김 → hero 손·휴대폰 띠 노출 |
| 0.50–0.80 | 가운데 띠(눈) 찢김. 두 눈 사이가 갈라짐 → hero 눈 띠 노출 |
| 0.85–1.00 | '야망솔루션'(위 띠), '이정준'(아래 띠) 등장 |

구간 값은 초기값이며 실제 화면을 보고 조정한다.

**생성 스크립트** `profile/scripts/build-opening-assets.mjs`
- `package.json`에 `"assets:opening": "node scripts/build-opening-assets.mjs"`로 등록한다. **`build` 스크립트에 넣지 않는다**(CI에 원본이 없음). 결과물을 커밋한다.
- 입력 경로는 `resolve(projectDir, '..', 'asset', 'opening')`이다.
- 두 원본을 각각 `bandLayout`의 % 좌표로 잘라 띠 6장을 만든다.
- 띠마다 폭 640 / 1280 / 2048의 AVIF(quality 55 내외)와 WebP(quality 75 내외)를 `profile/src/assets/opening/`에 출력한다. 파일명 예: `fallen-top-1280.avif`, `hero-middle-640.webp`.
- 확인용으로 "위·아래 띠는 hero, 가운데 띠만 〈타락천사〉"를 합성한 미리보기 PNG를 OS 임시 폴더에 출력한다.
- `sharp`를 devDependency로 추가한다.

**이미지 마크업**
- 띠마다 `<picture>`에 AVIF·WebP `srcset`과 `sizes`(액자 폭 기준)를 둔다.
- 〈타락천사〉 띠는 `loading="eager"`이고, 가장 큰 아래 띠에만 `fetchpriority="high"`를 준다. 프리렌더 HTML에 `<img>`가 들어 있어 브라우저가 일찍 발견하므로 별도 preload는 두지 않는다.
- hero 띠도 `loading="eager"`이되 `decoding="async"`로 둔다. 찢기 시작할 때 이미 로드되어 있어야 한다.

**Griun 폰트**
- Griun은 '야망솔루션' 표기에만 쓰인다(오프닝, Connect 제목, Footer 제목). 1.9MB TTF를 "야망솔루션" 다섯 글자만 남긴 woff2로 줄인다.
- 도구는 `subset-font` npm(devDependency) 또는 `pyftsubset` 중 하나를 쓰고, 생성 스크립트에 포함한다.
- 출력은 `profile/public/fonts/griun-yamang-v1.woff2`다. `public/`은 파일명이 해시되지 않으므로 이름에 버전을 붙여, 나중에 바꿀 때 S3 장기 캐시를 피한다.
- `index.html`에 `<link rel="preload" as="font" type="font/woff2" crossorigin>`을 추가하고, `index.css`의 `@font-face`를 새 파일로 교체한다.
- Griun 폰트 토큰(`--font-brand`)을 `@theme`에 추가하고, `ConnectSection`·`Footer`의 inline `fontFamily` style을 `font-brand`로 바꾼다.
- 기존 TTF를 삭제한다. 목표 용량은 10KB 이하다.

### 찢김 연출

**경로 생성** `profile/scripts/generate-tear-paths.mjs` → `profile/src/components/opening/tearPaths.ts`
- 띠마다 위(0%)에서 아래(100%)로 내려가는 꺾은선 하나를 만든다. 꼭짓점은 띠 높이에 비례해 24~40개다.
- 각 꼭짓점의 x = 중심선 + 저주파 노이즈(±1.5%) + 고주파 흔들림(±0.4%)이다. 시드를 고정하고 띠마다 다른 시드를 쓴다.
- 중심선은 위 띠 48%, 아래 띠 52%, **가운데 띠 55%**다. 55%는 〈타락천사〉의 보이는 눈(45%)과 그늘진 눈(약 65%) 사이이자, hero의 두 눈(48.8%, 약 59%) 사이다.
- 출력은 띠별 `left`/`right` 조각의 CSS `clip-path: polygon(...)` 문자열과 흰 가장자리 폴리곤이다.
  - 왼쪽 조각: `0 0` → 경로 → `0 100%`
  - 오른쪽 조각: 경로 → `100% 100%` → `100% 0`
- 결과를 정적 상수로 커밋한다. 런타임 생성은 하지 않는다.

**흰 섬유 가장자리**
- 각 조각의 찢긴 쪽에 경로를 따라 폭 0.3~0.9%(꼭짓점마다 무작위)의 띠 모양 폴리곤을 둔다.
- 인라인 SVG(`viewBox="0 0 100 100" preserveAspectRatio="none"`)로 그리고 채움색은 종이 속지색 `#f2ede3`이다.
- 보풀 질감은 정적 `feTurbulence` + `feDisplacementMap` 필터로 준다. 필터 값은 애니메이션하지 않는다.
- 조각 래퍼에 `will-change: transform`을 주어 필터가 한 번만 래스터화되게 한다. 스크롤 중 Performance 패널에 반복 Paint가 생기면, 가장자리를 생성 스크립트에서 PNG로 구워 쓰는 방식으로 바꾼다.

**조각 움직임** (띠 구간 진행도 0→1 기준, `useTransform`)
- 왼쪽 조각: `x` 0 → −60%(띠 폭 기준), `rotate` 0 → −4deg, `y` 0 → −2%
- 오른쪽 조각: `x` 0 → +60%, `rotate` 0 → +3deg, `y` 0 → −1.5%
- 두 조각 모두 구간의 마지막 30%에서 `opacity` 1 → 0
- 조각 아래 얕은 그림자는 별도 레이어로 두고 `opacity` 0 → 0.35 → 0으로 움직인다.
- 애니메이션 속성은 `transform`과 `opacity`만 쓴다. 띠 컨테이너는 `overflow: visible`, 액자는 `overflow: hidden`이 아니게 두어 조각이 액자 밖으로 날아가게 하되, 섹션에는 `overflow-x: clip`을 주어 가로 스크롤이 생기지 않게 한다.

### 텍스트·SEO·접근성

**글자 배치** (hero 띠 밝기 실측 기준 초기값)

| 문구 | 위치 | 스타일 | 근거 |
|------|------|------|------|
| '야망솔루션' | 위 띠 오른쪽 1/3, 세로 가운데, 오른쪽 정렬 | Griun, 버건디 `brand-red`, 큰 크기(액자 폭의 약 9%) | 위 띠 오른쪽 1/3은 밝은 회색(명도 약 205/255)이라 버건디가 잘 읽힘 |
| '이정준' | 아래 띠 왼쪽 아래, 왼쪽 정렬 | 세리프 `font-headline`, 흰색, 얕은 text-shadow | 아래 띠 왼쪽 아래는 어두운 재킷(명도 약 75~90)이라 흰 글자가 잘 읽힘 |

- 두 문구가 대각선 구도를 이룬다. 크기와 여백은 실제 화면을 보고 조정한다.
- 등장은 줄 단위 마스크 아래에서 올라오는 효과(`y` + `opacity`)다.
- '이정준'은 SSR부터 `h1`으로 존재하고 opacity·transform으로만 등장시킨다(`display: none` 금지). 기존 Hero의 `h1`("Lee JeongJun")은 Hero 삭제와 함께 없어지므로 페이지의 `h1`은 하나만 남는다.

**이미지 대체 텍스트**
- hero 띠: 세 장 중 가운데 띠에만 `alt="이정준 프로필 사진"`을 주고, 나머지 두 장은 `alt=""`로 둔다.
- 〈타락천사〉 띠: 모두 `alt=""` + `aria-hidden`이다. 섹션 안에 시각적으로 숨긴 텍스트로 "Alexandre Cabanel, 〈타락천사〉(1847), 몽펠리에 파브르 미술관"을 둔다.

**동작 줄이기** (`useReducedMotion`)
- 조각 이동·회전 없이, 띠마다 같은 진행도 구간에서 〈타락천사〉 띠가 opacity로 사라지고 hero가 드러난다.
- 글자는 0.85 구간에서 opacity만으로 나타난다.
