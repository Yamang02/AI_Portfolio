# P02: 찢김 오프닝 장면

## 목표

- 첫 화면에 경계 없는 정사각형 〈타락천사〉 한 장이 표시된다.
- 페이지가 열리면 자동으로, 〈타락천사〉가 hero.jpg의 흰 틈 두 곳을 따라 가로로 찢기고, 위 조각은 오른쪽, 아래 조각은 왼쪽, 가운데 눈 조각은 마지막에 오른쪽으로 종이가 말리듯 날아가며, 같은 자리에 띠 3개로 나뉜 hero.jpg가 드러난다.
- 가운데 눈 조각이 마지막까지 남아, 루시퍼의 눈이 이정준의 눈으로 바뀌는 순간이 장면의 정점이 된다.
- 애니메이션은 스크롤과 무관하게 한 번 재생되고, 사진 위에 문구를 올리지 않는다.
- 데스크톱(1440px)과 모바일(390px) 모두에서 끊김 없이 동작하고, `prefers-reduced-motion` 사용자에게는 찢김 없이 교차 페이드가 표시된다.
- 프리렌더된 `dist/index.html`에 '이정준' `h1`이 포함되고, 모바일 Lighthouse LCP가 2.5초 이하다.

## 수정 배경 (구현 에이전트용)

1차 구현(커밋 `6cfb23f2` 이후)은 이전 스토리보드대로 만들어졌다. 이전 스토리보드는 처음부터 띠 3개로 나뉜 〈타락천사〉가 스크롤에 맞춰 띠마다 **세로로** 찢기는 방식이었다. 사용자가 원한 연출과 달라 아래처럼 바뀐다.

| 항목 | 1차 구현 | 수정 후 |
|------|------|------|
| 처음 화면 | 띠 3개 + 흰 틈으로 나뉜 〈타락천사〉 | 틈 없는 정사각형 〈타락천사〉 한 장 |
| 찢김 방향 | 띠마다 세로로, 좌우 두 조각 | hero 흰 틈 두 곳을 따라 **가로로**, 위·가운데·아래 세 조각 |
| 사라지는 방향 | 띠마다 좌우로 벌어짐 | 위 → 오른쪽, 아래 → 왼쪽, 가운데 → 오른쪽(마지막) |
| 진행 방식 | 스크롤 연동(250svh 고정) | 자동 재생 1회, 섹션 높이 100svh |
| 종이 표현 | 흰 섬유 가장자리 + 그림자 | 흰 섬유 가장자리 + **찢긴 가장자리가 말려 올라감(CSS 3D)** |
| 사진 위 문구 | '야망솔루션', '이정준' | 없음 |

재사용하는 것: 띠 좌표(`bandLayout`), hero 띠 자산, 자산 생성 파이프라인 구조(alpha mask를 생성 단계에서 굽는 방식), Griun 서브셋, 콘텐츠 정리(Hero 삭제 등), `BandPicture`.

## 착수 전 확인 (구현 에이전트용)

- 컨셉 배경은 에픽 [Readme](./Readme.md) `## 특이점`의 "명함" 구성과 모션 원칙을 읽는다. 이 장면은 페이지에서 유일한 큰 연출이다.
- 파일 네이밍은 기존 `profile/src` 관례를 따른다(컴포넌트 PascalCase 파일, 훅 camelCase).
- 원본 자산 `asset/`는 수정·이동하지 않는다. gitignore 대상이며 CI에는 없다. 생성 스크립트 결과물만 커밋한다.
- 인라인 주석을 추가하지 않는다(사용자 선호).
- 명령은 `profile/`에서 실행한다: `pnpm assets:opening`, `pnpm dev`, `pnpm typecheck`, `pnpm build`, `pnpm preview`.
- **타이밍, 찢긴 선의 흔들림 폭, 말림 각도는 사용자가 화면을 보며 정한다.** 아래 값은 초기값이며, 재생 장면을 녹화하거나 단계별 스크린샷으로 확인받아 조정한다.

## 구현 상세

### 장면 구성

- 섹션 높이 `100svh`. 화면 고정(`sticky`)과 `useScroll`은 쓰지 않는다.
- 정사각형 액자를 가운데 둔다. 크기는 `min(100vw - 32px, 100svh - 176px)`로 시작한다(고정 Nav 약 88px 고려). 실제 화면을 보고 조정한다.
- 오프닝은 `main`의 첫 자식이며 `main`에 위쪽 여백을 두지 않는다.
- 액자 배경은 순백 `#ffffff`(hero.jpg 틈·여백 실측 색)다. 그 위에 hero 띠 3개를 % 좌표로 배치해 틈과 여백을 만든다.
- 그 위에 〈타락천사〉 조각 3개가 **액자 전체(0~100%)를 빈틈없이** 덮는다. 처음에는 조각 경계가 보이지 않아 한 장으로 보인다.
- 액자에 `perspective`(초기값 1200px)를 주고, 조각은 `transform-style: preserve-3d`다. 섹션에 `overflow: clip`을 주어 날아가는 조각 때문에 가로 스크롤이 생기지 않게 한다.

### 띠 좌표 (hero.jpg 실측, 4096px 기준, 기존과 동일)

| 구간 | y 범위 | 액자 대비 top / height |
|------|------|------|
| 바깥 여백 | 0–110 | — |
| 위 띠 | 111–1325 | 2.71% / 29.66% |
| 틈 1 | 1326–1437 | 32.37% / 2.73% |
| 가운데 띠 | 1438–1967 | 35.11% / 12.94% |
| 틈 2 | 1968–2079 | 48.05% / 2.73% |
| 아래 띠 | 2080–3981 | 50.78% / 46.44% |

띠 x 범위는 left 2.71%, width 94.51%다.

### 찢긴 선과 조각

**찢긴 선** `generate-tear-paths.mjs` → `tearPaths.json`·`tearPaths.ts` (기존 세로 경로를 대체)
- 가로 꺾은선 2개다. 선 1은 틈 1, 선 2는 틈 2 안을 지난다.
- 꼭짓점은 x 0~100%에 40~60개. 각 꼭짓점의 y = 틈 중심 + 저주파 노이즈 + 고주파 흔들림이다. **선이 틈 높이(2.73%) 밖으로 나가지 않게** 제한한다. 그래야 조각이 사라졌을 때 hero 띠 위에 〈타락천사〉 조각이 남지 않는다.
- 초기값: 저주파 ±0.9%, 고주파 ±0.3%. 시드를 고정하고 결과를 정적 데이터로 커밋한다.

**조각 3개**

| 조각 | 범위 | 찢긴 가장자리 | 사라지는 방향 |
|------|------|------|------|
| 위 | 0% → 선 1 | 아래쪽 | 오른쪽 |
| 가운데 | 선 1 → 선 2 | 위쪽·아래쪽 | 오른쪽 |
| 아래 | 선 2 → 100% | 위쪽 | 왼쪽 |

- 이웃한 조각의 찢긴 가장자리는 같은 선을 공유해 서로 맞물린다.

### 종이 말림 (CSS 3D)

- 조각마다 찢긴 가장자리를 따라 **말림 띠**를 별도 요소로 둔다. 높이 초기값은 조각 높이의 8%이며, 가운데 조각은 위·아래 가장자리에 각각 하나씩 둔다.
- 말림 띠는 앞면(그림)과 뒷면(종이 뒷면) 두 겹이다.
  - 앞면: 해당 영역의 그림 조각이다.
  - 뒷면: 미색 `#efe6d6` 바탕에 그림을 좌우 반전해 10% 정도 비치게 하고, 약한 그라데이션 음영을 준다.
  - 두 면 모두 `backface-visibility: hidden`이다. 뒷면은 `rotateX(180deg)`로 뒤집어 둔다.
- 말림 띠의 회전축(`transform-origin`)은 조각 몸통과 맞닿은 쪽 가장자리다. `rotateX`가 커지면 찢긴 가장자리가 들려 올라가며 뒷면이 보인다. 위 조각의 아래 가장자리는 위로, 아래 조각의 위 가장자리는 아래로 말린다.
- 조각 몸통은 말림 띠를 뺀 나머지다.
- 흰 섬유 가장자리는 찢긴 선을 따라 몸통 쪽과 말림 띠 쪽 모두에 붙인다. 생성 단계에서 PNG로 굽는다(기존 방식 유지).

**자산 생성** (`build-opening-assets.mjs` 수정)
- hero 띠 3장은 기존 그대로다.
- 〈타락천사〉에서 조각 몸통 3장, 말림 띠 앞면 4장(위 1, 가운데 2, 아래 1), 말림 띠 뒷면 4장을 찢긴 선 alpha mask로 잘라 생성한다. 섬유 가장자리 PNG도 함께 만든다.
- 런타임 `clip-path`와 필터는 쓰지 않는다(기존 원칙).
- 기존 세로 조각 자산(`fallen-*-left/right-*`, 조각 그림자 PNG)은 삭제한다.
- 확인용으로 "찢긴 선 2개를 〈타락천사〉와 hero 위에 겹친 미리보기"를 OS 임시 폴더에 출력한다. 선이 틈 밖으로 나가지 않는지 확인하는 용도다.

### 타임라인 (자동 재생, 초기값)

시작 조건: 〈타락천사〉 조각 이미지와 hero 띠 이미지가 모두 `decode()` 완료되고 0.6초 뒤. 처음 로드할 때 문서가 숨겨져 있으면(`document.hidden`) 보일 때 시작한다. 페이지를 열 때 한 번만 재생한다.

| 시간(s) | 동작 |
|------|------|
| 0.0–0.5 | 선 1이 왼쪽에서 오른쪽으로 찢어져 나감(섬유 가장자리가 자라남. 마스크의 `scaleX` 0→1). 위 조각이 0.3% 들림 |
| 0.4–1.2 | 위 조각: 말림 띠 `rotateX` 0→−110deg, 몸통 `rotateY` 0→−18deg·`rotateZ` 0→3deg·`x` 0→+115%, 마지막 30%에서 `opacity` 1→0 |
| 0.8–1.3 | 선 2가 오른쪽에서 왼쪽으로 찢어져 나감 |
| 1.2–2.0 | 아래 조각: 말림 띠 `rotateX` 0→+110deg, 몸통 `rotateY` 0→+18deg·`rotateZ` 0→−3deg·`x` 0→−115%, 마지막 30% `opacity` 1→0 |
| 2.0–2.4 | 정지. 루시퍼의 눈 조각만 hero의 머리·손 띠 사이에 남음 |
| 2.4–3.2 | 가운데 조각: 위·아래 말림 띠 각각 60deg, 몸통 `rotateY` −22deg·`x` +115%, 마지막 30% `opacity` 1→0 |

- 찢김이 번져 가는 방향은 날아갈 방향 쪽으로 진행한다. 위 조각은 왼쪽 → 오른쪽으로 찢긴 뒤 오른쪽으로, 아래 조각은 오른쪽 → 왼쪽으로 찢긴 뒤 왼쪽으로 날아간다.
- 이징: 찢김은 `easeIn`, 날아감은 `[0.6, 0, 0.8, 0.4]` 계열(가속)이다.
- Motion `useAnimate`의 시퀀스(`animate([...])`)로 구현한다. 애니메이션 속성은 `transform`과 `opacity`만 쓴다.
- 재생 중 사용자가 스크롤해도 애니메이션은 끝까지 진행한다.
- 재생이 끝나면 조각 요소를 DOM에서 제거하거나 `visibility: hidden`으로 두어, 이후 스크롤 시 합성 비용을 없앤다.

### 동작 줄이기 (`useReducedMotion`)

- 시작 조건은 같다. 조각 3개를 한 번에 0.6초 동안 `opacity` 1→0으로 바꾸고, 찢김·말림·이동은 하지 않는다.

### 텍스트·SEO·접근성

- 사진 위 문구는 없다.
- 섹션 안에 **시각적으로 숨긴 `h1`**("이정준")을 둔다. 페이지의 `h1`은 이것 하나다. P03에서 화면에 보이는 '이정준'이 생기면 그쪽을 `h1`로 옮기고 이 숨긴 `h1`은 제거한다(P03 문서에 명시).
- hero 띠: 가운데 띠에만 `alt="이정준 프로필 사진"`, 나머지 두 장은 `alt=""`.
- 〈타락천사〉 조각: 모두 `alt=""` + `aria-hidden`. 섹션 안에 시각적으로 숨긴 텍스트로 "Alexandre Cabanel, 〈타락천사〉(1847), 몽펠리에 파브르 미술관"을 둔다.
- LCP 대상은 〈타락천사〉 조각이다. 가장 큰 아래 조각에 `fetchpriority="high"`를 준다. 프리렌더 HTML에 `<img>`가 있으므로 별도 preload는 두지 않는다.

### Griun 폰트

- 서브셋 woff2(`public/fonts/griun-yamang-v1.woff2`)와 `--font-brand` 토큰은 유지한다.
- 오프닝에서 '야망솔루션'을 쓰지 않으므로 Griun은 Connect·Footer에만 쓰인다. 첫 화면에 필요 없으니 **`index.html`의 폰트 preload를 제거한다.**

### 콘텐츠

- `content.json`의 `opening` 블록: `heading`("이정준", 숨긴 h1), `heroAlt`, `artworkCredit`. `brand`·`name` 등 문구 필드는 제거한다.
- Hero 관련 정리(`hero` 블록, `ProfileHero`, `site.heroGreeting`·`site.heroImageAlt`, `Hero.tsx`, `profile_teacher.jpg` 삭제)는 1차 구현대로 유지한다.

### 범위 밖

- Nav, 정체성 이하 섹션은 바꾸지 않는다.
- 데스크톱 좌우 여백 처리, Nav 재설계는 Readme `## 후속`에서 다룬다.
- 실제 종이처럼 둥글게 말리는 WebGL 표현(Readme `## 후속`의 B안). 이번 수정은 CSS 3D(A안)다.
