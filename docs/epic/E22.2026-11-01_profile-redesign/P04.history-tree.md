# P04: 이력 나무 연표

## 목표

- 소개 다음 구간에 이력 섹션이 표시된다. 섹션에 들어오면 화면이 고정(sticky)되고, 스크롤에 따라 연도 단계 5개(2026 → 2025 → 2023 → 2022 → 2019)가 차례로 한 장면씩 바뀐다. 2019 단계는 교사 경력(상명고·배재고)을 묶는다.
- 고정 화면 가운데에 항상 꽉 찬 굵은 세로 줄기(8px)가 있다. 왼쪽 상단의 연도 슬롯이 숫자 휠처럼 굴러 바뀌고, 그 아래 연도 목차가 현재 단계를 강조해 진행도를 보여주며 눌러서 이동할 수 있다.
- 한 장면(연도 단계)에는 카드가 최대 4개 들어간다. 카드 종류(경력·교육·산출물)와 상관없이 모든 카드는 같은 형태(이미지 중심 미디어 + 텍스트)다. 이미지가 준비되지 않은 카드는 칠해 둔 빈칸을 미디어로 쓴다.
- 줄기 위 노드는 시간 순서(시작 시점이 최신인 것이 위)로 놓이고, 카드는 그 순서대로 오른쪽 → 왼쪽 → 오른쪽 → 왼쪽으로 번갈아 놓인다. 좌우는 종류와 무관하다.
- 카드와 줄기를 잇는 선은 모두 같은 45° 꺾인 모양이고, 종류는 선과 노드로만 구분한다: 경력은 굵은 실선 + 채운 노드, 교육은 대시선 + 빈 노드, 산출물은 얇은 실선 + 노드 없음.
- 스크롤을 멈추면 가장 가까운 연도 단계로 정렬되고(방향 인식 스냅), 아래로 내려오다 고정 화면이 뷰포트 55% 안쪽까지 들어오면 고정 시작 위치로 끌어당긴다. 위로 빠져나가거나 마지막 단계에서 아래로 나갈 때는 붙잡지 않는다. 스크롤 가로채기(JS 휠 차단)는 쓰지 않는다. `prefers-reduced-motion` 사용자에게는 고정 없이 연도별 정적 목록이 보이고 영상은 정지 이미지로 대체된다.
- 프리렌더된 `dist/index.html`에 모든 카드의 제목·설명·기간과 링크가 포함된다.
- 기존 주요 활동 벤토·활동 모달·관심사 섹션과 이들만 쓰던 콘텐츠·자산이 제거된다.

## 착수 전 확인 (구현 에이전트용)

- 컨셉 배경은 에픽 [Readme](./README.md) `## 특이점`의 "명함" 구성과 모션 원칙을 읽는다. 이 Phase의 주 연출은 "고정 화면 + 연도 슬롯 스크러빙" 하나다. 이력은 에픽에서 오프닝 외에 화면 고정을 쓰는 유일한 구간이며, 장면 연출이 아니라 탐색 장치로 쓴다.
- 이력 섹션에는 섹션 머리(진입 여백·구분선·라벨)를 두지 않는다. 섹션 제목 `h2`("History")는 `sr-only`로 스크린리더에만 남긴다.
- 파일 네이밍은 기존 `profile/src` 관례를 따른다(컴포넌트 PascalCase 파일, 훅 camelCase). 인라인 주석을 추가하지 않는다(사용자 선호).
- 문구(한 줄 설명)는 아래 콘텐츠 표의 초안으로 구현하고, 사용자가 화면을 본 뒤 확정한다.

## 구현 상세

### 레이아웃

**구조**: 섹션 머리 없이 트랙 컨테이너만 둔다. 트랙 높이는 `100svh + (단계 수 − 1) × 45svh`이고, 그 안의 `position: sticky; top: 0; height: 100svh` 프레임이 화면에 고정된다. 트랙 안에 단계마다 위치 마커를 45svh 간격으로 둔다(CSS 스냅은 쓰지 않음, 아래 스냅 규칙 참고).

**데스크톱** (`md` 이상, 프레임 내용 최대 폭 `max-w-6xl`)

```
┌──────────────────── 고정 프레임 (100svh, nav 아래부터) ────────────────────┐
│  2025                               █                                     │
│  2026 · 2025 · 2023 · 2022 · 2019   █                                     │
│                                     █ ─╮ ┌────────┐ (주)리콘랩스          │ ← ① 2025.09 경력: 굵은 실선 + 채운 노드
│                                     ● ─╯ │ 빈칸   │ Software Engineer     │
│     Sesac 강동지점  ┌────────┐ ╭- -   █   └────────┘                       │
│   Multi Modal AI   │ 빈칸   │- ╯ - -○                                     │ ← ② 2025.06 교육: 대시선 + 빈 노드
│                    └────────┘       █ ─╮ ┌────────┐ 성미회 아카이브   ↗   │
│                                     █ ─╯ │ 사진   │                       │ ← ③ 2025.02 산출물: 얇은 실선, 노드 없음
│                                     █    └────────┘                       │
└───────────────────────────────────────────────────────────────────────────┘
  스크롤 ↓ → 슬롯이 다음 연도로 굴러가고, 현재 장면은 위로(−48px) 빠지며 다음 장면이 아래(+48px)에서 올라온다
```

- **줄기**: 프레임 가운데 8px(소개 벤토 틈과 같은 값), 항상 `primary`로 꽉 차 있다. 진행도를 표시하지 않고 나무 줄기 역할만 한다.
- **연도 슬롯 + 목차**: 프레임 왼쪽 상단에 둔다. 높이 1.1em 창 안에서 단계 라벨 목록을 `y`로 굴린다(0.5초, ease-out 계열, 세리프 `text-8xl`, 보조 색, `tabular-nums`). 바로 아래 작은 연도 목차를 두고, 현재 단계는 `primary` 굵게(`aria-current="step"`), 나머지는 흐리게 표시한다. 목차 버튼을 누르면 그 단계 마커로 부드럽게 스크롤한다.
- **장면**: 단계마다 장면 하나를 겹쳐 두고 활성 단계만 보인다. 비활성 장면은 `opacity 0`, 이전 단계 `y −48px`, 다음 단계 `y +48px`, `pointer-events: none`. 카드 영역 시작 높이는 프레임 기준 `max(15rem, 34svh)`로 모든 장면이 같다.
- **카드 수**: 한 장면에 최대 4개. 넘으면 콘텐츠 로드 시 오류를 던진다.
- **노드 순서(시간순)**: 장면 안의 카드는 `start` 내림차순(최신이 위)으로 코드가 정렬한다. 같으면 콘텐츠 순서를 따른다. 페이지 전체가 위 = 최신, 아래 = 과거이므로 장면 안도 같은 방향이다.
- **좌우 배정**: 정렬된 순서의 0·2번째는 오른쪽, 1·3번째는 왼쪽. 종류와 무관하다. 첫 카드를 오른쪽에 두는 이유는 왼쪽 상단을 연도 슬롯이 차지하기 때문이다.
- **세로 배치(엇갈림)**: n번째 카드의 위쪽은 `n × 88px`. 노드 간격도 88px이고, 같은 쪽의 카드(n, n+2)는 176px 떨어져 카드 높이(약 138px)와 겹치지 않는다. 카드 4개의 전체 높이는 약 400px다.
- **카드**: 종류와 상관없이 같은 카드. 미디어(16:10, 220px)를 줄기 쪽에, 텍스트(제목·한 줄 설명·기간, 링크가 있으면 `↗`)를 바깥쪽에 둔다. 왼쪽 카드는 좌우 반전(텍스트 오른쪽 정렬). 제목은 세 종류 모두 같은 글꼴·크기다.
- **연결선과 노드**: 모든 선은 같은 기하다. 줄기 가장자리에서 시작해 45°로 올라간 뒤 꺾여 수평으로 카드 미디어 위쪽(위에서 19px)에 닿는다(데스크톱 상승 28px, 폭 60px). 왼쪽은 좌우 반전. 노드는 줄기 중심, 선의 시작점 높이에 놓인다.

| 종류 | 선 | 노드 |
|------|----|------|
| 경력 `career` | 4px 실선 | 24px, 테두리 4px, 활성 시 `primary`로 채움 |
| 교육 `course` | 3px 대시선(대시 6px · 간격 5px) | 20px, 테두리 3px, 속은 `surface`(비움) |
| 산출물 `work` | 2px 실선 | 없음 |

- **선 그리기 연출**: 활성 시 선이 줄기에서 카드 쪽으로 그려진다(0.45초, 0.15초 지연). 대시선은 `pathLength` 애니메이션이 `stroke-dasharray`를 덮어써서 대시가 사라지므로, 선 자체는 정적으로 두고 같은 경로의 실선 마스크(`<mask>`)에 `pathLength` 0 → 1을 준다. 세 종류 모두 같은 방식으로 그린다.
- 2026 장면에는 강의 산출물 1~2개를 더 넣을 자리가 있다(현재 2개, 최대 4개).

**모바일**

- 줄기는 왼쪽 레일(8px 유지), 연도 슬롯은 레일 오른쪽 위(`text-5xl`)에 둔다.
- 카드는 모두 레일 오른쪽에 시간순으로 쌓는다(엇갈림 없음, 간격 16px). 카드는 96px 미디어 + 텍스트 가로형이다.
- 선은 데스크톱과 같은 모양을 짧게 줄인다(상승 14px, 폭 26px). 선 굵기·대시·노드 규칙은 데스크톱과 같다.
- 카드 4개 장면이 390×844 프레임 안에 들어가야 한다.

### 주 연출: 고정 화면 + 연도 슬롯 스크러빙

- 진행도는 Motion `useScroll({ target: 트랙, offset: ['start start', 'end end'] })`. 활성 단계는 `round(진행도 × (단계 수 − 1))`이며 `useMotionValueEvent`로 상태에 반영한다.
- **스냅 (방향 인식, 스크롤 멈춤 140ms 후 판정)**:
  - 트랙 위에서 아래로 내려오는 중이고 트랙 상단이 뷰포트 높이 55% 안쪽이면 → 고정 시작 위치(첫 단계)로 부드럽게 이동.
  - 트랙 안(첫 단계 ~ 마지막 단계)이면 → 가장 가까운 단계 마커로 이동.
  - 마지막 단계를 지나 반 단계 이내에서 위로 스크롤 중이면 → 마지막 단계로. 아래로 나가는 중이면 붙잡지 않는다.
  - 첫 단계에서 위로 빠져나갈 때는 붙잡지 않는다.
  - 터치 중(손가락이 화면에 있는 동안)에는 판정하지 않는다.
  - CSS `scroll-snap`은 쓰지 않는다. proximity 스냅이 섹션 경계에서 위로 빠져나가는 스크롤까지 되돌려서 방향을 구분할 수 없기 때문이다.
- 키보드: 다른 단계의 링크에 포커스가 들어오면(`onFocusCapture`) 그 단계 마커 위치로 부드럽게 스크롤해 활성화한다.
- 프리렌더 HTML에는 모든 단계의 내용이 DOM에 있다(비활성 장면은 투명도만 0). 첫 화면에서 섹션은 화면 아래에 있으므로 하이드레이션 깜빡임이 없다.
- `prefers-reduced-motion`: 트랙·고정·스냅 마커 없이 연도 제목 + 장면을 차례로 나열한 정적 목록을 렌더한다. 장면 배치(시간순·좌우 교차·선 종류)는 고정 화면과 같고, 선은 처음부터 다 그려진 상태다.

### 카드 미디어

- 사진: `<picture>` AVIF/WebP, `loading="lazy"`, 400/800폭과 카드 폭 기준 `sizes`.
- 디자인랩 영상: `muted loop playsInline`, `preload="none"`, `poster` 지정. 카드가 활성 장면이고 화면 안에 있을 때만 재생하고 벗어나면 일시정지한다. `prefers-reduced-motion`에서는 재생하지 않고 poster만 보인다.
- 워드마크(야망솔루션 대표): 16:10 틀 안에 "야망솔루션"을 `font-brand` + `text-brand-red`로 가운데 정렬한다. 틀 배경은 섹션보다 한 단계 짙은 surface 토큰, 글자 크기는 틀 폭에 맞춰 `clamp`로 정한다. 이미지 파일을 만들지 않는다.
- 빈칸(`placeholder`): 사진이 준비되지 않은 카드는 16:10 틀을 `surface-container-high`로 칠해 둔다. 사진이 오면 해당 항목의 `media`만 바꾼다.
- 카드 hover/focus: 미디어 확대(1.03)만 준다. 포커스 링은 카드 전체에 보인다.

### 접근성·SEO

- 섹션은 `id="history"`, `aria-labelledby`로 `sr-only` 제목(`h2`)에 연결한다. 장면마다 `sr-only` 연도 `h3`를 둔다.
- 장면 카드 목록은 `<ul>`, 카드는 `<li>`이며 DOM 순서는 시간순(화면의 노드 순서와 같음)이다. 기간은 `<time dateTime="2025-09">` 형식이고, 진행 중이면 끝 기간은 콘텐츠의 "현재" 라벨을 쓴다(렌더 시점 날짜 계산 금지. SSR·hydration 일치).
- 줄기·노드·연결선·연도 슬롯 장식은 `aria-hidden`이다. 연도 목차는 실제 버튼이다.
- `href`가 있는 카드는 하나의 `<a target="_blank" rel="noopener noreferrer">`이고, 접근 가능한 이름은 "{제목} 사이트 (새 창)"이다. 없는 카드는 링크가 아니다. 미디어(사진·영상·워드마크·빈칸)는 `aria-hidden`이다.

### 콘텐츠

- `content.json`에 `history` 블록을 둔다: `label`("History"), `presentLabel`("현재"), `linkSuffix`("사이트 (새 창)"), `steps[]`.
- `steps`는 화면 순서(최신 단계부터)로 적는다. 단계는 `id`, `label`(연도 슬롯에 표시), `entries[]`(최대 4개)를 가진다. 단계 묶음은 콘텐츠가 정한다(2019·2021 교사 경력을 `label: "2019"` 한 단계로 묶음).
- 모든 항목은 같은 카드 필드를 가진다: `id`, `kind`(`career` | `course` | `work`), `start`("YYYY.MM"), `end?`("YYYY.MM", 없으면 진행 중), `title`, `desc`, `media`, `href?`. `kind`는 선·노드 모양에만 쓰인다. `work`는 `href`가 필수다.
- `media`: `{ type: 'image', asset }` | `{ type: 'video', asset }` | `{ type: 'wordmark', text }` | `{ type: 'placeholder' }`.

## 체크리스트

- [ ] 이력 섹션에 들어오면 화면이 고정되고, 스크롤에 따라 2026 → 2025 → 2023 → 2022 → 2019 다섯 장면이 차례로 바뀐 뒤 고정이 풀려 연결 구간으로 넘어간다.
- [ ] 연도 슬롯이 왼쪽 상단 같은 자리에서 숫자 휠처럼 바뀌고, 다음 연도 숫자가 창 밖으로 비치지 않는다.
- [ ] 줄기는 항상 꽉 차 있고, 연도 목차가 현재 단계를 강조하며 목차를 누르면 그 단계로 이동한다.
- [ ] 모든 카드(경력·교육·산출물)가 같은 미디어 + 텍스트 형태이고, 사진이 없는 카드는 칠해 둔 빈칸이 보인다. 야망솔루션 대표는 워드마크 카드다.
- [ ] 장면 안 카드가 시작 시점 최신순으로 위에서 아래로 놓이고, 오른쪽 → 왼쪽으로 번갈아 엇갈려 배치된다. 같은 쪽 카드끼리 겹치지 않는다.
- [ ] 한 장면에 카드가 5개 이상인 콘텐츠는 로드 시 오류가 난다. `work`에 `href`가 없어도 오류가 난다.
- [ ] 세 종류의 선이 같은 45° 꺾인 모양이고, 경력은 4px 실선 + 채운 노드, 교육은 3px 대시선 + 빈 노드, 산출물은 2px 실선 + 노드 없음으로 구분된다. 선은 장면이 활성화될 때 줄기에서 카드 쪽으로 그려지고, 교육 대시선도 대시가 유지된 채 그려진다.
- [ ] 1440×900과 1280×720에서 카드 4개 장면이 프레임 안에 들어가고 연도 슬롯과 겹치지 않는다. 390×844 모바일에서 레일 하나로 접히고 카드 4개가 한 화면에 들어가며 가로 스크롤이 없다.
- [ ] 링크가 있는 카드를 누르면 해당 사이트가 새 창으로 열리고, 링크가 없는 카드는 눌리지 않는다. 역할 태그는 없다.
- [ ] 단계 사이에서 스크롤을 멈추면 가까운 단계로 스냅되고, 아래로 내려오다 트랙 상단이 뷰포트 55% 안쪽에서 멈추면 고정 시작 위치로 끌려온다. 첫 단계에서 위로, 마지막 단계에서 아래로 나갈 때는 붙잡히지 않는다.
- [ ] 이력 섹션에 구분선과 "History" 라벨이 보이지 않고, 스크린리더는 섹션 제목을 읽는다.
- [ ] 디자인랩 영상은 카드가 활성 장면이고 화면 안에 있을 때만 재생되고, 벗어나면 멈춘다. 첫 로드에 영상 파일을 받지 않는다(Network 탭).
- [ ] OS "동작 줄이기"를 켜면 고정 없이 연도별 정적 목록이 같은 배치 규칙으로 보이고, 영상 대신 poster가 보인다.
- [ ] 키보드 Tab으로 연도 목차 버튼과 링크 카드 3개에 차례로 포커스가 가고, 다른 단계의 카드에 포커스가 가면 그 단계로 스크롤되며 포커스 링이 카드 전체에 보인다. 스크린리더가 카드 9개와 "{제목} 사이트 (새 창)"을 읽는다.
- [ ] `dist/index.html`에 카드 9개의 제목·설명·기간과 링크 3개가 포함되고, 브라우저 콘솔에 hydration 경고가 없다.
- [ ] 주요 활동·관심사 섹션과 활동 모달이 페이지에 없고, nav의 "이력" 링크가 이 섹션으로 이동한다.
- [ ] `src/assets/history/` 400폭 AVIF가 장당 40KB 이하, 영상이 2MB 이하이며, `asset/` 원본은 커밋되지 않았고 `asset/` 없이 `pnpm build`가 성공한다.
- [ ] `profile/public/`에 `featured_activity_*` 파일과 `video/`가 남아 있지 않다.
- [ ] 한 줄 설명·연도 크기·카드 크기·엇갈림 간격(88px)·선 굵기·단계 간격(45svh)·전환 속도를 사용자가 화면으로 확인하고 확정했다.
