# P04: 이력 나무 연표

## 목표

- 소개 다음 구간에 이력 섹션이 표시된다. 섹션에 들어오면 화면이 고정(sticky)되고, 스크롤에 따라 연도 단계 5개(2026 → 2025 → 2023 → 2022 → 2019)가 차례로 한 장면씩 바뀐다. 2019 단계는 교사 경력(상명고·배재고)을 묶는다.
- 고정 화면 가운데에 항상 꽉 찬 굵은 세로 줄기(8px)가 있다. 왼쪽 상단의 연도 슬롯이 숫자 휠처럼 굴러 바뀌고, 그 아래 연도 목차(2026 · 2025 · 2023 · 2022 · 2019)가 현재 단계를 강조해 진행도를 보여주며 눌러서 이동할 수 있다.
- 각 장면은 왼쪽 경력 슬롯 최대 2개, 오른쪽 산출물 슬롯 최대 2개의 고정 자리로 구성되고, 자리는 모든 장면에서 같은 높이다. 경력은 미디어(이미지·워드마크, 준비 전에는 칠해 둔 빈칸) + 텍스트 카드이며 4px 선이 45° 꺾여 줄기로 이어진다. 교육과정은 미디어 없는 작은 점 항목이다. 산출물 2개(디자인랩, 성미회 아카이브)는 2px 선이 45° 꺾여 이어지는 카드다. 야망솔루션은 경력(대표)으로 두고 워드마크와 사이트 링크를 붙인다. 역할 태그는 표시하지 않는다.
- 스크롤을 멈추면 가장 가까운 연도 단계로 정렬되고(방향 인식 스냅), 아래로 내려오다 고정 화면이 뷰포트 55% 안쪽까지 들어오면 고정 시작 위치로 끌어당긴다. 위로 빠져나가거나 마지막 단계에서 아래로 나갈 때는 붙잡지 않는다. 스크롤 가로채기(JS 휠 차단)는 쓰지 않는다. `prefers-reduced-motion` 사용자에게는 고정 없이 연도별 정적 목록이 보이고 영상은 정지 이미지로 대체된다.
- 프리렌더된 `dist/index.html`에 모든 항목의 조직·설명·기간과 가지 링크가 포함된다.
- 기존 주요 활동 벤토·활동 모달·관심사 섹션과 이들만 쓰던 콘텐츠·자산이 제거된다.

## 착수 전 확인 (구현 에이전트용)

- 컨셉 배경은 에픽 [Readme](./README.md) `## 특이점`의 "명함" 구성과 모션 원칙을 읽는다. 이 Phase의 주 연출은 "고정 화면 + 연도 슬롯 스크러빙" 하나다. 이력은 에픽에서 오프닝 외에 화면 고정을 쓰는 유일한 구간이며, 장면 연출이 아니라 탐색 장치로 쓴다. 스크롤 가로채기는 쓰지 않는다.
- 이력 섹션에는 섹션 머리(진입 여백·구분선·라벨)를 두지 않는다. 소개 섹션 바로 뒤에 고정 프레임이 이어지고, 섹션 제목 `h2`("History")는 `sr-only`로 스크린리더에만 남긴다.
- 파일 네이밍은 기존 `profile/src` 관례를 따른다(컴포넌트 PascalCase 파일, 훅 camelCase). 인라인 주석을 추가하지 않는다(사용자 선호).
- 야망솔루션 가지의 미디어는 이미지가 아니라 **브랜드 워드마크**다. ④ 연결 구간 제목과 같은 그리운경찰감성체(`font-brand`, `griun-yamang-v1.woff2`) + `text-brand-red`의 "야망솔루션" 글자를 HTML 텍스트로 렌더한다. 나머지 원본은 기존 `profile/public/`의 성미회 이미지와 디자인랩 영상을 `asset/history/`로 복사해 쓴다.
- 문구(한 줄 설명)는 아래 콘텐츠 표의 초안으로 구현하고, 사용자가 화면을 본 뒤 확정한다.

## 구현 상세

### 레이아웃

**구조**: 섹션 머리 없이 트랙 컨테이너만 둔다. 트랙 높이는 `100svh + (단계 수 − 1) × 45svh`이고, 그 안의 `position: sticky; top: 0; height: 100svh` 프레임이 화면에 고정된다. 트랙 안에 단계마다 위치 마커를 45svh 간격으로 둔다(CSS 스냅은 쓰지 않음, 아래 스냅 규칙 참고).

**데스크톱** (`md` 이상, 프레임 내용 최대 폭 `max-w-6xl`)

```
┌──────────────── 고정 프레임 (100svh, nav 아래부터) ──────────────────┐
│  2026  ← 연도 슬롯(왼쪽 상단)        █                               │
│  2026 · 2025 · 2023 · 2022 · 2019  █ ← 연도 목차 / 줄기는 항상 꽉 참    │
│                                  █   ╱── [영상]    디자인랩      ↗    │
│  2026.01 — 현재  야망솔루션 대표 ━━●  ╱                               │
│                    강의·개발 사업  █   ╱── [워드마크] 야망솔루션    ↗    │
│                                  █  ╱                                │
│                                  █                                   │
└──────────────────────────────────────────────────────────────────────┘
  스크롤 ↓ → 슬롯이 2025로 굴러가고, 현재 장면은 위로(−48px) 빠지며 다음 장면이 아래(+48px)에서 올라온다
```

- **줄기**: 프레임 가운데 8px(소개 벤토 틈과 같은 값), 항상 `primary`로 꽉 차 있다. 진행도를 표시하지 않고 나무 줄기 역할만 한다.
- **연도 슬롯 + 목차**: 프레임 왼쪽 상단(경력 열 위)에 둔다. 높이 1.1em 창 안에서 단계 라벨 목록을 `y`로 굴린다(0.5초, ease-out 계열, 세리프 `text-8xl`, 보조 색, `tabular-nums`). 바로 아래 작은 연도 목차를 두고, 현재 단계는 `primary` 굵게(`aria-current="step"`), 나머지는 흐리게 표시한다. 목차 버튼을 누르면 그 단계 마커로 부드럽게 스크롤한다.
- **장면과 고정 슬롯**: 단계마다 3열 그리드(왼쪽 | 줄기 3rem | 오른쪽)를 겹쳐 두고 활성 단계만 보인다. 그리드 2행이 슬롯이며, 경력·산출물이 각각 n번째면 n행에 놓인다. 슬롯 시작 높이는 프레임 기준 `max(15rem, 34svh)`로 모든 장면이 같다(세로 가운데 정렬은 장면마다 1행 위치가 달라져 쓰지 않음). 비활성 장면은 `opacity 0`, 이전 단계 `y −48px`, 다음 단계 `y +48px`, `pointer-events: none`. 한쪽 슬롯이 2개를 넘으면 콘텐츠 로드 시 오류를 던진다.
- **왼쪽(경력)**: 카드는 미디어(16:10, 220px)를 줄기 쪽에, 텍스트(조직·설명·기간, 링크면 `↗`)를 바깥쪽에 오른쪽 정렬로 둔다. 미디어 위쪽에서 수평으로 나온 4px 선이 45° 아래로 꺾여 줄기 위 24px 점(테두리 4px, 활성 시 채움)에 닿는다. 미디어가 준비되지 않은 경력은 `surface-container-high`로 칠한 빈칸(`placeholder`)을 둔다. 교육과정은 미디어·꺾인 선 없이 16px 외곽선 점과 한 단계 낮춘 텍스트로 둔다.
- **오른쪽(산출물)**: 점 없이 줄기 오른쪽 가장자리에서 2px 선이 45° 우상향으로 올라간 뒤 꺾여 수평으로 카드 미디어에 닿는다. 카드는 미디어(16:10, 220px) + 텍스트(제목·한 줄 설명·기간·`↗`). 선 굵기 위계: 줄기 8px > 경력 4px > 산출물 2px. 두 선 모두 활성 시 `pathLength` 0 → 1(0.45초)로 그려진다.
- 2026 오른쪽 두 번째 슬롯은 강의 산출물(추가 예정) 자리다. 해당 단계 `entries`에 `work` 항목을 넣기만 하면 붙는다.

**모바일**

- 줄기는 왼쪽 레일(8px 유지), 연도 슬롯은 레일 오른쪽 위(`text-5xl`)에 둔다.
- 장면 내용은 모두 레일 오른쪽에 경력 → 교육과정 → 산출물 순으로 쌓는다. 카드는 96px 미디어 + 텍스트 가로형이고, 경력은 4px, 산출물은 2px 꺾인 선을 짧게 줄여 레일에 잇는다.
- 가지 선은 데스크톱과 같은 꺾인 2px 선을 짧게 줄여 쓴다.

### 주 연출: 고정 화면 + 연도 슬롯 스크러빙

- 진행도는 Motion `useScroll({ target: 트랙, offset: ['start start', 'end end'] })`. 활성 단계는 `round(진행도 × (단계 수 − 1))`이며 `useMotionValueEvent`로 상태에 반영한다.
- **스냅 (방향 인식, 스크롤 멈춤 140ms 후 판정)**:
  - 트랙 위에서 아래로 내려오는 중이고 트랙 상단이 뷰포트 높이 55% 안쪽이면 → 고정 시작 위치(첫 단계)로 부드럽게 이동. 사진·카드가 화면에 들어온 시점에 고정이 걸린다.
  - 트랙 안(첫 단계 ~ 마지막 단계)이면 → 가장 가까운 단계 마커로 이동.
  - 마지막 단계를 지나 반 단계 이내에서 위로 스크롤 중이면 → 마지막 단계로. 아래로 나가는 중이면 붙잡지 않는다.
  - 첫 단계에서 위로 빠져나갈 때는 붙잡지 않는다.
  - 터치 중(손가락이 화면에 있는 동안)에는 판정하지 않는다.
  - CSS `scroll-snap`은 쓰지 않는다. proximity 스냅이 섹션 경계에서 위로 빠져나가는 스크롤까지 되돌려서 방향을 구분할 수 없기 때문이다.
- 키보드: 다른 단계의 링크에 포커스가 들어오면(`onFocusCapture`) 그 단계 마커 위치로 부드럽게 스크롤해 활성화한다.
- 프리렌더 HTML에는 모든 단계의 내용이 DOM에 있다(비활성 장면은 투명도만 0). 첫 화면에서 섹션은 화면 아래에 있으므로 하이드레이션 깜빡임이 없다.
- `prefers-reduced-motion`: 트랙·고정·스냅 마커 없이 연도 제목 + 장면을 차례로 나열한 정적 목록을 렌더한다.

### 경력 이미지 (자산 대기)

- 연도 대표 이미지 대신 경력마다 이미지를 붙인다(리콘랩스, 디아이티, 배재고, 상명고). 이미지가 오기 전에는 `media: { type: 'placeholder' }`로 칠해 둔 빈칸을 둔다.
- 원본은 `asset/history/careers/`에 두고 `build-history-assets.mjs`에 단계를 더해 AVIF/WebP 400·800폭 16:10을 만든 뒤, `ProfileHistoryMedia`의 `image` 자산 키를 늘리고 해당 경력의 `media`를 바꾼다.

### 가지 미디어

- 워드마크(야망솔루션): 썸네일과 같은 16:10 틀 안에 "야망솔루션"을 `font-brand` + `text-brand-red`로 가운데 정렬한다. 틀 배경은 섹션보다 한 단계 짙은 surface 토큰, 글자 크기는 틀 폭에 맞춰 `clamp`로 정한다. 이미지·자산 파일을 만들지 않는다. hover/focus는 다른 카드와 같은 확대만 준다. 폰트 서브셋에 "야망솔루션" 글리프가 있는지(④ 연결 제목이 이미 사용) 화면으로 확인한다.
- 썸네일: `<picture>` AVIF/WebP, `loading="lazy"`, 400/800폭과 카드 폭 기준 `sizes`.
- 디자인랩 영상: `muted loop playsInline`, `preload="none"`, `poster` 지정. 카드가 화면 안에 있을 때만 재생하고 벗어나면 일시정지한다. `prefers-reduced-motion`에서는 재생하지 않고 poster만 보인다.
- 카드 hover/focus: 미디어 흑백 → 컬러가 아니라, 기본 컬러에 밝기·확대(1.03) 정도만 준다. 포커스 링은 카드 전체에 보인다.

### 접근성·SEO

- 섹션은 `id="history"`, `aria-labelledby`로 섹션 라벨(`h2`)에 연결한다.
- 목록은 `<ol>`, 항목은 `<li>`이며 기간은 `<time dateTime="2025-09">` 형식이다. 진행 중이면 끝 기간은 콘텐츠의 "현재" 라벨을 쓴다(렌더 시점 날짜 계산 금지. SSR·hydration 일치).
- 줄기·점·가로 연결선·연도 장식은 `aria-hidden`이다. 연도 정보는 `<time>`으로 이미 전달된다.
- 가지 카드는 하나의 `<a target="_blank" rel="noopener noreferrer">`이고, 접근 가능한 이름은 "{제목} 사이트 (새 창)"이다. 썸네일 `alt`는 비운다(제목이 링크 이름을 대신함). 영상과 워드마크 틀은 `aria-hidden`이다(워드마크 글자가 제목과 겹쳐 읽히지 않게).

### 콘텐츠

- `content.json`에 `history` 블록을 둔다: `label`("History"), `presentLabel`("현재"), `linkSuffix`("사이트 (새 창)"), `steps[]`.
- `steps`는 화면 순서(최신 단계부터)로 적는다. 단계는 `id`, `label`(연도 슬롯에 표시), `entries[]`를 가진다. 단계 묶음은 콘텐츠가 정한다(2019·2021 교사 경력을 `label: "2019"` 한 단계로 묶음).
- `entries`는 단계 안에서 시작 시점 최신순이며, `kind`로 구분하는 discriminated union이다.
  - 공통: `id`, `start`("YYYY.MM"), `end?`("YYYY.MM", 없으면 진행 중)
  - `career`: `org`, `desc`, `media`(아래 미디어 중 하나, 준비 전에는 `{ type: 'placeholder' }`), `href?`
  - `course`: `org`, `desc`
  - `work`: `title`, `desc`, `href`, `media`(`{ type: 'image', asset }` | `{ type: 'video', asset }` | `{ type: 'wordmark', text }` | `{ type: 'placeholder' }`)
