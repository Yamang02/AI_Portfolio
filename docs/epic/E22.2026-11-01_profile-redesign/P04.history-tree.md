# P04: 이력 나무 연표

## 목표

- 소개 다음 구간에 이력 섹션이 표시된다. 가용 높이에 카드 최대 4개가 들어오면 화면이 고정(sticky)되고, 스크롤에 따라 연도 단계 5개(2026 → 2025 → 2023 → 2022 → 2019)가 차례로 한 장면씩 바뀐다. 최소 가독 크기로도 들어오지 않으면 모든 연도를 일반 스크롤로 나열한다. 2019 단계는 교사 경력(상명고·배재고)을 묶는다.
- 고정 화면 가운데에 항상 꽉 찬 세로 줄기(기본 6px)가 있다. 첫 슬롯에서는 위쪽 끝, 마지막 슬롯에서는 아래쪽 끝만 둥글게 마감한다. 왼쪽 상단의 연도 슬롯이 숫자 휠처럼 굴러 바뀌고, 그 아래 연도 목차가 현재 단계를 강조해 진행도를 보여주며 눌러서 이동할 수 있다.
- 마지막 연도 슬롯(2019)에서 오프닝과 같은 스크롤 안내를 표시해 다음 연결 섹션으로 내려갈 수 있음을 알린다. 이력 트랙과 연결 섹션 사이에는 4~6vh의 여백을 둔다.
- 한 장면(연도 단계)에는 카드가 최대 4개 들어간다. 카드 종류(경력·교육·산출물)와 상관없이 모든 카드는 같은 형태(이미지 중심 미디어 + 기관·프로젝트 제목 + 역할·과정·요약 부제 + 기간)다. 이미지가 준비되지 않은 카드는 칠해 둔 빈칸을 미디어로 쓴다.
- 줄기 위 노드는 시간 순서(시작 시점이 최신인 것이 위)로 놓이고, 카드는 그 순서대로 오른쪽 → 왼쪽 → 오른쪽 → 왼쪽으로 번갈아 놓인다. 좌우는 종류와 무관하다.
- 카드와 줄기를 잇는 선은 모두 같은 45° 꺾인 모양이고, 종류는 선과 노드로만 구분한다: 경력은 굵은 실선 + 채운 노드, 교육은 대시선 + 빈 노드, 산출물은 얇은 실선 + 노드 없음.
- 스크롤을 멈추면 가장 가까운 연도 단계로 정렬되고(방향 인식 스냅), 아래로 내려오다 고정 화면이 뷰포트 30% 안쪽까지 들어오면 고정 시작 위치로 끌어당긴다. 위로 빠져나가거나 마지막 단계에서 아래로 나갈 때는 붙잡지 않는다. 스크롤 가로채기(JS 휠 차단)는 쓰지 않는다. `prefers-reduced-motion` 사용자에게는 고정 없이 연도별 정적 목록이 보이고 영상은 정지 이미지로 대체된다.
- 프리렌더된 `dist/index.html`에 모든 카드의 제목·부제·기간과 링크가 포함된다.
- 기존 주요 활동 벤토·활동 모달·관심사 섹션과 이들만 쓰던 콘텐츠·자산이 제거된다.

## 착수 전 확인 (구현 에이전트용)

- 컨셉 배경은 에픽 [Readme](./README.md) `## 특이점`의 "명함" 구성과 모션 원칙을 읽는다. 이 Phase의 주 연출은 "고정 화면 + 연도 슬롯 스크러빙" 하나다. 이력은 에픽에서 오프닝 외에 화면 고정을 쓰는 유일한 구간이며, 장면 연출이 아니라 탐색 장치로 쓴다.
- 이력 섹션에는 섹션 머리(진입 여백·구분선·라벨)를 두지 않는다. 섹션 제목 `h2`("History")는 `sr-only`로 스크린리더에만 남긴다.
- 파일 네이밍은 기존 `profile/src` 관례를 따른다(컴포넌트 PascalCase 파일, 훅 camelCase). 인라인 주석을 추가하지 않는다(사용자 선호).
- 문구(부제)는 아래 콘텐츠 표의 초안으로 구현하고, 사용자가 화면을 본 뒤 확정한다.

## 구현 상세

### 레이아웃

**구조**: 섹션 머리 없이 내용 컨테이너만 둔다. `historyLayout.ts`가 실제 내용 폭·100svh 높이·nav 높이·root 글자 크기·최대 카드 수로 크기와 고정 가능 여부를 계산한다. ResizeObserver가 내용·100svh 측정 요소·nav를 관찰한다. 고정 모드의 트랙 높이는 `100svh + (단계 수 − 1) × 45svh`이고, 그 안의 `position: sticky; top: 0; height: 100svh` 프레임이 화면에 고정된다. 트랙 안에 단계마다 위치 마커를 45svh 간격으로 둔다(CSS 스냅은 쓰지 않음, 아래 스냅 규칙 참고). 일반 스크롤 모드는 트랙 없이 연도를 나열한다. SSR과 첫 클라이언트 렌더도 이 경로로 일치시킨다.

아래 px 수치는 root 글자 크기 16px 기준이며, 글자 크기를 바꾸면 같은 비율로 조정한다. 사이트 전체 font-size나 CSS zoom은 변경하지 않는다.

- **줄기**: 프레임 가운데 6px, 항상 `primary`로 꽉 차 있다. 진행도를 표시하지 않고 나무 줄기 역할만 한다. 첫 슬롯에서 위쪽 끝, 마지막 슬롯에서 아래쪽 끝을 둥글게 마감한다. 일반 스크롤 목록에서는 양 끝을 모두 둥글게 한다.
- **마지막 스크롤 안내**: 마지막 슬롯에서 오프닝의 `SCROLL` 안내를 같은 모양으로 표시한다. 프레임 아래쪽에 안내 높이(기본 51px) + 바닥 여백 24px + 줄기와의 간격 12px를 예약하므로 줄기·카드와 겹치지 않는다. 일반 스크롤 모드는 둥근 줄기 끝 다음에 정적으로 표시한다.
- **연도 슬롯 + 목차**: 넓은 화면은 프레임 왼쪽 상단에 큰 연도 슬롯과 작은 목차를 둔다. 슬롯은 높이 1.1em 창 안에서 단계 라벨 목록을 `y`로 굴린다(0.5초, ease-out 계열, 세리프 72px, 보조 색, `tabular-nums`). compact는 큰 연도 슬롯을 감추고 목차만 표시한다. 현재 단계는 `primary` 굵게(`aria-current="step"`), 나머지는 흐리게 표시한다. 목차 버튼을 누르면 그 단계 마커로 부드럽게 스크롤한다.
- **장면**: 단계마다 장면 하나를 겹쳐 두고 활성 단계만 보인다. 비활성 장면은 `opacity 0`, 이전 단계 `y −36px`, 다음 단계 `y +36px`, `pointer-events: none`. 프레임 내용은 nav 아래 16px부터 시작하고, 넓은 화면 카드 영역은 내용 위쪽 48px부터 시작한다.
- **카드 수**: 한 장면에 최대 4개. 넘으면 콘텐츠 로드 시 오류를 던진다.
- **노드 순서(시간순)**: 장면 안의 카드는 `start` 내림차순(최신이 위)으로 코드가 정렬한다. 같으면 콘텐츠 순서를 따른다. 페이지 전체가 위 = 최신, 아래 = 과거이므로 장면 안도 같은 방향이다.
- **좌우 배정**: 정렬된 순서의 0·2번째는 오른쪽, 1·3번째는 왼쪽. 종류와 무관하다. 첫 카드를 오른쪽에 두는 이유는 왼쪽 상단을 연도 슬롯이 차지하기 때문이다.
- **썸네일 크기**: 16:10. 선호 폭은 `min(256px, max(192px, 16.5vw), (내용 폭 − 36px) / 2 − 30px − 144px)`다. 양쪽 텍스트 칸을 확보하고, 가용 높이에 맞는 허용 폭과 비교해 더 작은 값을 사용한다. 최소 192px로도 카드 묶음이 들어가지 않으면 일반 스크롤로 전환한다. 1440×900에서는 약 238×149px다.
- **세로 배치(엇갈림)**: 노드 간격 `gap = 썸네일 높이 / 2 + 18px`. 묶음 높이는 `(카드 수 − 1) × gap + 썸네일 높이`다. 고정 장면에서 묶음은 카드 영역 세로 가운데에 놓는다. 같은 쪽 카드(n, n+2)는 `썸네일 높이 + 36px` 떨어져 겹치지 않는다. 카드 4개 전체 높이는 1440×900에서 약 425px다. 공통 계산 결과를 `--history-thumb-width`, `--history-thumb-height`, `--history-card-gap`으로 전달한다.
- **연도 영역과의 관계**: 첫 카드는 오른쪽이라 연도 슬롯과 겹치지 않는다. 왼쪽 첫 카드(두 번째 순서)는 묶음 위쪽에서 `gap`만큼 아래에 놓여 연도·목차 아래에서 시작한다. 가용 높이는 `100svh − (nav 높이 + 16px) − 아래 예약 공간 − 카드 영역 시작 여백`이다. 카드 높이 상한은 `(가용 높이 − (카드 수 − 1) × 18px) / (1 + (카드 수 − 1) / 2)`로 계산한다.
- **카드**: 종류와 상관없이 같은 정보 위계를 쓴다. 기관·프로젝트명을 제목으로, 역할·과정·요약을 부제로, 기간을 별도 표기한다. 넓은 화면은 미디어를 줄기 쪽에, 텍스트를 바깥쪽에 둔다(왼쪽 카드는 좌우 반전). compact는 21:10 배너에 제목·기간만 겹치고 부제는 숨기되 DOM에 둔다. 링크가 있는 카드는 사용자가 제공한 외부 링크 SVG를 반투명 사각 백드롭과 함께 미디어 우상단에 놓고, SVG 선 굵기는 2px로 한다. 제목은 자연스러운 단어 경계를 유지하며 최대 두 줄로 제한한다.
- **연결선과 노드**: 모든 선은 같은 기하다. 줄기 가장자리에서 시작해 45°로 올라간 뒤 꺾여 수평으로 카드 미디어 위쪽(위에서 14.25px)에 닿는다(넓은 화면 상승 21px, 폭 45px). 왼쪽은 좌우 반전. 노드는 줄기 중심, 선의 시작점 높이에 놓인다.

| 종류 | 선 | 노드 |
|------|----|------|
| 경력 `career` | 3px 실선 | 18px, 테두리 3px, 활성 시 `primary`로 채움 |
| 교육 `course` | 2.25px 대시선(대시 4.5px · 간격 3.75px) | 15px, 테두리 2.25px, 속은 `surface`(비움) |
| 산출물 `work` | 1.5px 실선 | 없음 |

- **선 그리기 연출**: 활성 시 선이 줄기에서 카드 쪽으로 그려진다(0.45초, 0.15초 지연). 대시선은 `pathLength` 애니메이션이 `stroke-dasharray`를 덮어써서 대시가 사라지므로, 선 자체는 정적으로 두고 같은 경로의 실선 마스크(`<mask>`)에 `pathLength` 0 → 1을 준다. 세 종류 모두 같은 방식으로 그린다.
- 2026 장면은 강사 활동, 야망디자인 페이지, 야망솔루션 홈페이지의 세 카드로 구성한다.

- 줄기는 왼쪽 레일(6px), 연도 목차는 레일 오른쪽 위에 둔다. 큰 현재 연도 표시는 숨기고 슬롯 목록만 표시한다. 카드 영역은 프레임 내용 위쪽 80px부터다.
- **배너 스택**: 카드는 레일 오른쪽 21:10 배너다. 선호 폭은 `min(420px, 내용 폭 − 33px)`이며 시간순으로 쌓고 엇갈림은 없다. 배너 사이 간격은 9px다. 390×844의 네 카드 장면에서는 높이 제약에 따라 약 304.5×145px다.
- **글은 배너 위에 겹친다**: 배너 아래쪽에 두 줄 이하 제목과 기간을 두고 어두운 배경을 깐다. 글은 흰색이다. 부제는 표시하지 않는다(DOM에는 남김). 링크 카드의 외부 링크 SVG는 반투명 사각 백드롭과 함께 배너 오른쪽 위에 둔다.
- 선은 넓은 화면과 같은 모양을 짧게 줄인다(상승 10.5px, 폭 19.5px). 배너 위쪽에 닿는다. 선 굵기·대시·노드 규칙은 넓은 화면과 같다.
- 높이 상한은 `(가용 높이 − (카드 수 − 1) × 9px) / 카드 수`다. 288px(내용 폭이 더 좁으면 선호 폭) 이상을 유지할 수 있으면 썸네일을 줄여 고정을 유지한다. 그렇지 않으면 일반 스크롤로 모든 연도를 나열한다. 별도 내부 스크롤은 없다.
- root 16px·nav 54px 수식 기준으로 390×844의 네 카드 묶음은 약 577px(가용 607px), 768×1024는 747px(가용 787px)다. 390×667은 일반 스크롤이다. 이는 계산 검증이며 실제 브라우저 측정과 구분한다.
- 일반 스크롤에서는 연도 목차와 각 연도 제목을 sticky로 두고 네이티브 연도 앵커를 제공한다. compact에서는 큰 연도 제목을 시각적으로 숨기고 목차만 sticky로 유지한다. 크기 변경으로 경로가 바뀌면 현재 연도 마커로 위치를 보존한다.

### 주 연출: 고정 화면 + 연도 슬롯 스크러빙

- 진행도는 Motion `useScroll({ target: 트랙, offset: ['start start', 'end end'] })`. 활성 단계는 `round(진행도 × (단계 수 − 1))`이며 `useMotionValueEvent`로 상태에 반영한다.
- **스냅 (방향 인식, 스크롤 멈춤 140ms 후 판정)**:
  - 트랙 위에서 아래로 내려오는 중이고 트랙 상단이 뷰포트 높이 30% 안쪽이면 → 고정 시작 위치(첫 단계)로 부드럽게 이동.
  - 트랙 안(첫 단계 ~ 마지막 단계)이면 → 가장 가까운 단계 마커로 이동.
  - 마지막 단계를 지나 반 단계 이내에서 위로 스크롤 중이면 → 마지막 단계로. 아래로 나가는 중이면 붙잡지 않는다.
  - 첫 단계에서 위로 빠져나갈 때는 붙잡지 않는다.
  - 터치 중(손가락이 화면에 있는 동안)에는 판정하지 않는다.
  - CSS `scroll-snap`은 쓰지 않는다. proximity 스냅이 섹션 경계에서 위로 빠져나가는 스크롤까지 되돌려서 방향을 구분할 수 없기 때문이다.
- 키보드: 다른 단계의 링크에 포커스가 들어오면(`onFocusCapture`) 그 단계 마커 위치로 부드럽게 스크롤해 활성화한다.
- 프리렌더 HTML은 일반 스크롤 목록이며 모든 단계의 내용이 DOM에 있다. 첫 클라이언트 렌더도 같은 초기값을 사용하고, 레이아웃 측정 후 고정 가능 여부를 결정한다. 콘솔 hydration 경고와 실제 전환은 브라우저에서 별도 확인한다.
- `prefers-reduced-motion`: 트랙·연도 휠·스냅 마커 없이 연도 제목 + 장면을 차례로 나열한다. compact에서는 큰 연도 제목을 숨기고 슬롯 목록만 sticky로 유지한다. 장면 배치(시간순·좌우 교차·선 종류)는 고정 화면과 같고, 선은 처음부터 다 그려진 상태다. 줄기 끝을 둥글게 마감하고 스크롤 안내는 목록 끝에 정적으로 표시한다.
