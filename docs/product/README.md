# Product documentation

Own stable product meaning, vocabulary, user-visible behavior, guarantees, and experience.

## Initial scope
AI_Portfolio contains the main portfolio, profile site, administration surfaces, and related content/service capabilities. Define domain owners incrementally from verified code and existing requirements, not from guessed categories.

## Authoring
- Product documents must not prescribe component names, DB fields, or technical paths as business truths.
- New domain/behavior/experience documents require evidence from current code or an explicitly approved new product decision.
- Existing product claims remain in their current documents until reviewed and moved.
- Current implementation details belong to [Dev](../dev/README.md) or code.
